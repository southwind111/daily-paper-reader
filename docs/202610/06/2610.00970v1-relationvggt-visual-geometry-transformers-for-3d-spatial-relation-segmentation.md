## 摘要
近期，3D重建的进展已从逐场景优化发展到前馈推理，语义场景理解也随之跟进——然而现有方法仍局限于以对象为中心的感知，忽略了对象之间的空间关系。我们将3D空间关系分割形式化为一种前馈、无需位姿的多视角设定：给定视觉指定的主体和关系文本查询，模型在未获得目标类别名称的情况下跨视角分割目标。为此，我们提出RelationVGGT，一种新颖的前馈框架，它将来自视觉基础模型的语义特征与来自3D几何基础模型的几何感知表示相融合，并利用关系Transformer进行以主体为条件的跨视角关系预测——既不需要逐场景优化，也不需要已知相机位姿。此外，我们提供了一套基于ScanNet++、使用VLM和LLM构建的全自动标注流程，从而能够为这一新任务生成可扩展的训练数据。

## Abstract
Recent advances in 3D reconstruction have progressed from per-scene optimization to feed-forward inference, and semantic scene understanding has followed suit -- yet existing methods remain confined to object-centric perception, neglecting spatial relations between objects. We formulate 3D spatial relation segmentation in a feed-forward, pose-free multi-view setting: given a visually specified subject and a relational text query, the model segments the target across views without receiving its category name. To this end, we propose RelationVGGT, a novel feed-forward framework that integrates semantic features from a visual foundation model with geometry-aware representations from a 3D geometry foundation model and leverages a relation transformer for subject-conditioned, cross-view relation prediction -- requiring neither per-scene optimization nor known camera poses. We additionally provide a fully automated annotation pipeline built on ScanNet++ with VLMs and LLMs, enabling scalable training data generation for this new task.

# RelationVGGT 论文总结

## 1. 核心问题与研究背景

- **领域演进脉络**：3D 重建已从 NeRF / 3DGS 的逐场景优化走向 DUSt3R、VGGT、Pi3 等前馈式几何基础模型（无需相机位姿与 SfM 流程）；语义场景理解也随之从 LangSplat / OpenGS（逐场景优化）发展到 PanSt3R / Uni3R（前馈、多视图一致）。
- **核心缺口**：上述方法几乎全部是**以对象为中心**的感知，把场景视为孤立实体的集合，忽略了对象之间的空间关系（如"显示器放在桌上""杯子在键盘旁边"）。
- **任务定义**：论文形式化 **3D 空间关系分割（3D spatial relation segmentation）**，设定为**前馈、无位姿（pose-free）多视图**场景：
  - 输入：多视图图像集 I、参考视图 I_r 中的**主体二值掩码 M_s**、关系文本查询 q（如 "resting on"）；
  - 输出：在所有目标视图上一致地分割出满足该关系的**目标对象**；
  - 关键约束：**不给目标类别名**，目标必须由"主体 + 关系"共同推断。
- **为何困难**：需要同时具备语义身份理解、方向性空间关系推理、跨视图几何一致性三重能力。
- **现有方案的局限**：
  - RelationField 在辐射场上学习对象间关系，但依赖逐场景优化与已标定位姿，需在整个 3D 体素空间中搜索目标，可扩展性与泛化性差；
  - 视频-语言模型（VideoLISA、SA2VA、UniPixel）缺少 3D 场景表示，在大视角变化下难以维持对象对应关系。

## 2. 方法论

### 2.1 核心思想
- **将先前的"体素关系搜索"重构为图像网格上的逐像素关系预测**：给定参考视图主体掩码，直接在目标视图像素网格上预测"该像素与主体的关系特征"，从而摆脱场景特定的 3D 场与体积搜索。
- 学习函数 f_θ(I_r, M_s, I_tgt, u) → R_t，其中 R_t = {r_t(u) | u ∈ I_t} 为每视图的关系特征图；通过与语言嵌入做特征–文本相似度实现开放词汇分割。

### 2.2 关键技术细节
- **双流特征提取与融合**：
  - 语义流：DINOv2 提供密集 patch 级对象语义；
  - 几何流：Pi3 编码器 token（取任务预测头之前的表示），保留多视图几何信息；
  - 二者通道拼接后经 **input mixer**（线性投影 + 少量带 RoPE 的 Transformer 块）映射为联合 token F_n ∈ R^{P×d_f}。
- **关系 Transformer（主体条件化 + 跨视图）**：
  - 主体表示不压缩为单一池化向量，而是**保留参考视图全部 patch token 并按掩码置零非主体 patch**（F^s_r = M̄_s ⊙ F_r），保留主体的空间布局与细粒度语义；
  - 所有目标视图 token 拼接为单一序列 Z^0 = Concat({F_t})；
  - 交替执行**主体条件交叉注意力**与**全局自注意力**：Z̄^ℓ = CrossAttn(Z^ℓ, F^s_r)，Z^{ℓ+1} = SelfAttn(Z̄^ℓ)，使表示同时具备主体条件化与多视图感知能力。
- **掩码解码**：用 DPT head 将 patch 级 token 上采样为像素对齐的关系特征图 R_t（输出分辨率 512×388）。
- **3D 几何输出**：借助 Pi3 点解码器预测点图与置信度图，使每个关系特征可关联到 3D 点，形成置信度感知的 3D 关系表示。
- **训练目标（多查询监督）**：空间关系是"多对一"的（"standing on" ≈ "on" ≈ "supported by"），因此对同一目标掩码用多条兼容查询独立监督，各自计算 sigmoid focal loss，再叠加 Dice loss：
  - L_mask = w_focal · L^multi-q_focal + w_dice · L_dice；focal 参数 α=0.75、γ=1.5。
- **推理**：z_t(u;q) = r_t(u)^T e(q)，经 sigmoid 得到分数，固定阈值 τ=0.3 二值化；作者发现无需像特征场方法那样做负提示归一化或 softmax。

### 2.3 自动标注管线（数据侧贡献）
- 基于 **ScanNet++**（含 3D 实例级点标注）构建，流程为：
  1. 以对象实例为节点、关系为边初始化场景图；将实例掩码投影到有位姿 RGB 帧，用 **Set-of-Mark (SoM) prompting** 标记可见对象，查询 VLM（Qwen3-VL-8B）得到逐帧关系提案；
  2. **多视图一致性过滤**：同一对象对需在 ≥K=3 帧中被预测出同一关系才保留；
  3. **几何过滤**：用 3D 包围盒与实例质心，剔除包围盒不重叠且质心距离超阈值的物理不合理关系；
  4. **LLM 复述（GPT-5.2）**：将已验证三元组改写为多样化表述（如 (TV, hanging on, wall) → "mounted on"/"installed on"），提升查询词汇多样性。
- 文本编码器采用 **Jina Embeddings v3**（沿用 RelationField 设置），关系 Transformer 采用 ViT-S 配置。

## 3. 实验设计

- **数据集与 Benchmark**：
  - 自建人工标注 benchmark，覆盖 **ScanNet++**（RelationField 的 26 个样本 + 新增 14 个 = 40 条）、**LERF**（3 个场景 31 条关系）、**Replica**（8 个场景 48 条关系），共 **119 条查询、28 种谓词**；
  - 采样时使用中等步长以保证视角多样性；指标为 **mIoU（主）** 与 **mAcc@0.25（IoU>0.25 的查询占比）**。
- **对比方法**：
  - 开放词汇 3D 场景理解：LangSplat、OpenGaussian、RelationField、RelationField†（去掉目标对象检索、仅用关系嵌入）；
  - 视频基础模型：VideoLISA、SA2VA、UniPixel（把多视图当视频输入）；
  - 3D 指代分割：MVGGT、ReferSplat（适配其原生文本接口，非严格同输入对比）。
- **主要结果**：
  - 平均 **mIoU 0.382 / mAcc 0.549**，显著优于最强基线 RelationField（0.303 / 0.480）；
  - Replica 0.446/0.640、ScanNet++ 0.445/0.675 均领先；LERF 上 mIoU 0.254 略低于 RelationField 的 0.276（但 mAcc 0.332 vs 0.410 亦低），作者归因于密集杂乱的桌面小物体场景；
  - 按相机基线分组后，UniPixel 在小基线（0.423）有竞争力但随基线增大明显退化，本方法在三档基线（0.417 / 0.404 / 0.366）保持稳定。
- **消融实验**：
  - 输入特征：用点图位置编码替代 Pi3 特征（0.370）、仅 Pi3（0.422）、仅 DINOv2（0.370），均低于完整方案（0.445）；
  - 注意力结构：仅交叉注意力（0.399）、VGGT 式交替注意力（0.394）均更差；
  - 训练目标：单标签 focal（0.406）明显下降，验证多查询监督的必要性；
  - 标注管线：去掉几何边过滤（0.398），说明物理不合理监督有害。
- **鲁棒性与附加分析**：
  - 主体掩码规格：GT（0.382）、SAM2 单点（0.383）、SAM2 单框（0.382）几乎无差异；Qwen3-VL+SAM2（0.357）、GroundingDINO+SAM2（0.322）下降，归因于实例歧义而非边界精度（58% 参考视图含多个同类实例）；

- **查询措辞与同义改写**：由于训练时对同一目标用多条兼容查询做独立监督，模型对措辞变化不敏感；把 benchmark 查询换成 LLM 复述出的同义表达后，性能基本保持稳定，说明学到的不是与特定模板绑定的捷径，而是较通用的关系语义。这一鲁棒性来自自动标注管线中的 LLM 复述环节，属于数据侧设计对模型行为的直接反哺。
- **关系方向性与对称性**：论文区分了方向性谓词（"on"、"above"、"hanging on"）与近似对称谓词（"next to"、"near"）；前者要求主体/目标角色不可交换，后者对调主体与目标后仍应成立。实验显示交换主体掩码后方向性关系的 mIoU 大幅跌落，验证模型确实在建模方向而非仅靠共现。
- **3D 关系表示**：得益于 Pi3 点解码器，每个关系特征图可对应到带置信度的 3D 点，形成置信度感知的 3D 关系表示。作者以置信度加权方式将 2D 关系特征反投影到 3D，可视化结果显示"主体—关系—目标"在 3D 空间中呈合理的空间布局，且与 LERF/ScanNet++ 的实例标注有较好吻合；这为后续在 3D 上直接做关系查询（而非仅出 2D 掩码）留下接口。

## 4. 定性结果与失败模式

- **成功案例**：模型能处理需要细粒度语义与空间联合推理的查询，例如"显示器 resting on 桌子"在视角变化很大时仍保持一致；对"某物挂在其上的墙"这类以背景/大结构为目标的关系也能给出较完整掩码，说明目标不限于前景小物体。
- **典型失败**：
  - **密集杂乱小物体**（LERF 桌面场景）：同类实例高度重叠，参考视图掩码本身存在歧义，主体条件化被"错误的主体"污染，导致目标选错；
  - **遮挡与参考视图不可见**：当满足关系的关键证据（如接触面）在参考视图中被遮挡时，模型缺少可用的关系线索；
  - **空间包含型关系**（如 "inside"）：仅凭多视图外观难以恢复被容器遮挡的内部目标，本质上是可见性而非关系推理的限制；
  - **长尾谓词**：出现频次极低的谓词因标注数据稀疏，性能明显低于高频谓词。

## 5. 贡献总结

1. **任务层面**：首次形式化"前馈、无位姿多视图下的 3D 空间关系分割"，把主体掩码 + 关系文本作为输入、跨视图一致的目标分割作为输出，且不给出目标类别名。
2. **方法层面**：
   - 把体素/辐射场中的关系搜索改写为图像网格上的逐像素关系预测，去掉场景特定优化与体积搜索；
   - 双流（DINOv2 语义 + Pi3 几何）融合 + 主体条件化与全局自注意力交替的关系 Transformer；
   - 保留参考视图全部 patch 并按掩码置零的主体表示，避免池化带来的空间信息损失；
   - 面向"多对一"关系的多查询监督目标。
3. **数据层面**：基于 ScanNet++ 的自动标注管线，VLM 逐帧提案 + 多视图一致性过滤 + 3D 几何合理性过滤 + LLM 复述，兼顾规模、物理合理性与查询词汇多样性。
4. **评测层面**：跨 ScanNet++ / LERF / Replica 的人工标注 benchmark（119 条查询、28 种谓词），并给出按相机基线分组的分析，揭示视频基础模型在大基线下的退化。

## 6. 局限与未来工作

- **输入依赖**：仍需参考视图的主体掩码，未做端到端的主体定位；主体歧义（同类多实例）是主要误差来源之一。
- **单主体单关系**：每次查询只处理一个主体与一条关系，未建模组合式/链式关系（如"键盘旁边的杯子下面的桌垫"）或多主体联合查询。
- **谓词覆盖受限**：关系类别受自动标注管线所覆盖谓词的限制，长尾与抽象关系（如 "belonging to"、"part of"）仍薄弱。
- **动态与交互**：仅在静态室内场景验证，未涉及人–物交互、可操作关系或时序变化。
- **3D 输出未量化评估**：3D 关系表示目前只有可视化与定性证据，缺少如 3D 关系 IoU 或点级关系精度的定量指标。
- **潜在方向**：与 3D 场景图 / 可操作 affordance 结合、支持多主体与组合查询、把关系预测扩展为可用于机器人操作的关系场，以及用更强的 3D 基础模型替换 Pi3 编码器以提升几何精度。

## 7. 总体评价

- **优点**：问题设定清晰且有实际价值（从"物体在哪"到"物体之间怎样"）；方法改动克制而有效——关键洞察是关系可以在 2D 像素网格上直接预测，从而绕开逐场景 3D 优化这一可扩展性瓶颈；消融覆盖输入特征、注意力结构、训练目标、标注管线四个层面，结论一致指向各设计的必要性；benchmark 跨三个数据集、给出按基线分组的细粒度分析，比单一平均分更有说服力。
- **可商榷之处**：与 RelationField 的对比在 LERF 上并不占优，作者的解释合理但缺乏进一步实验（如增大训练谓词覆盖、针对密集场景的专门评测）来支撑；部分基线（MVGGT、ReferSplat）输入协议不同，属"适配式"对比，需谨慎解读；benchmark 规模（119 条）偏小，单条查询的波动可能影响排名稳定性。
- **定位**：本文更像是一次"把 3D 空间关系理解拉回前馈范式"的范式性工作，方法本身的组件多为已有模块的巧妙组合，主要贡献在于任务形式化、2D 关系预测的重构思路与配套数据/评测；其价值可能更多体现在为后续组合关系推理、3D 场景图与具身应用提供基线上。
