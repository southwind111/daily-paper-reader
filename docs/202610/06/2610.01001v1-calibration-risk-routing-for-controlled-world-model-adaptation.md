## 摘要
基于模型的强化学习（MBRL）可以利用模拟经验，但从模拟器到目标域的偏移会造成模型选择问题：在目标数据有限时，校正模拟器与直接拟合目标都可能失败。我们提出模型校正世界模型（Model-Corrected World Model, MC-WM），它将初始目标数据划分为互不相交的拟合、选择和校准分区，并部署标准化校准风险更低的模型族。一个学习到的置信信号和确定性有效性谓词对单步想象策略更新进行加权，而不改写物理奖励。我们在三个受控的带接触多关节动力学（MuJoCo）偏移上评估了 540 个唯一的报告运行单元；其中一个精确路由单元在预部署工件门控后重复运行，共得到 541 次完成执行。

## Abstract
Model-based reinforcement learning (MBRL) can exploit simulated experience, but a simulator-to-target shift creates a model-selection problem: correcting the simulator and fitting the target directly can each fail under limited target data. We introduce the Model-Corrected World Model (MC-WM), which separates initial target data into disjoint fit, selection, and calibration partitions and deploys the family with lower standardized calibration risk. A learned confidence signal and deterministic validity predicates weight one-step imagined policy updates without rewriting physical rewards. We evaluate 540 unique reported run cells across three controlled Multi-Joint dynamics with Contact (MuJoCo) shifts; one exact-routing cell was repeated after a pre-deployment artifact gate, giving 541 completed executions.

## 1. 论文的核心问题与整体含义

- **研究背景**：基于模型的强化学习（MBRL）可利用模拟器数据训练策略，但当模拟器与目标环境之间存在动力学偏移（simulator-to-target shift）时，会出现模型选择难题。
- **核心问题**：
  - 在目标数据有限的情况下，**修正模拟器**（学习残差模型）与**直接拟合目标**（从零拟合目标世界模型）都可能失败。
  - 策略优化会利用模型拟合分布下罕见的预测错误，导致想象 rollout 不可靠。
  - 因此存在两个耦合问题：**应部署哪一类目标模型族**（残差 vs. 直接目标），以及**每个想象转移应以多大权重影响策略学习**。
- **整体含义**：论文提出 **Model-Corrected World Model（MC-WM）**，将初始目标数据划分为互不相交的拟合、选择、校准分区，用标准化校准风险选择模型族，并通过置信信号与确定性谓词对一步想象策略更新加权，而不改写物理奖励。其目标不是宣称残差或符号方法普遍更优，而是提供一种**校准的模型族选择机制**与**有界信任机制**。

## 2. 方法论：核心思想与关键技术

### 2.1 核心思想：校准风险路由

- 用同一批初始目标数据拟合两个候选：
  - **残差候选** \(c^{M_R}\)：对冻结的模拟器集成模型 \(c^{M_S}\) 进行状态与奖励修正。
  - **直接目标候选** \(c^{M_D}\)：直接将同一概率集成架构拟合到目标转移。
- 将初始 10,000 条目标转移按 80%/10%/10% 划分为：
  - **拟合集 \(I_{\text{fit}}\)**：估计参数；
  - **选择集 \(I_{\text{sel}}\)**：选择稀疏特征、为直接集成提供早停；
  - **校准集 \(I_{\text{cal}}\)**：在拟合与早停中完全不使用，用于计算路由风险。
- 定义联合一步目标：
  - \(z_i = [s_{i+1}-s_i; r_i]\)，即状态增量与奖励拼接。
- 对候选 \(m \in \{R,D\}\)，计算标准化校准风险：
  - \(R_m\) 为校准集上各坐标标准化误差的均方根，标准化尺度来自拟合集标准差。
- 部署规则：
  - 若 \(R_D < R_R\)，选择直接目标族；否则保留残差族（平局保留残差）。
- **随机流隔离**：直接候选拟合使用独立随机流，确保模型族选择不会通过消耗随机数改变下游策略、回放或优化器初始化。

### 2.2 残差候选：锁定稀疏支持 + 掩码神经剩余

- 冻结模拟器集成预测状态增量 \(\hat{u}_S(x)\) 与奖励 \(\hat{\rho}_S(x)\)。
- 残差状态修正目标为观测目标增量减去模拟器预测增量。
- 残差候选预测：
  - 状态：\(s_t + \hat{u}_S(x_t) + \hat{\Delta}_s(x_t)\)；
  - 奖励：\(\hat{\rho}_S(x_t) + \hat{\Delta}_{r,\zeta}(x_t)\)。
- 状态修正由两部分组成：
  - **稀疏分支** \(B\tilde{\Theta}(x)\)：基于二次多项式特征库，用 STLSQ 选择特征并锁定支持与顺序；
  - **掩码神经剩余** \(g_\psi(\mu \odot \tilde{\Theta}(x))\)：单隐层 32 单元 SiLU，输出层零初始化，只使用已报告支持内的特征。
- 奖励校正为单隐层 64 单元 ReLU 网络。
- 在线重拟合只更新系数、神经剩余、奖励与终止头，**不新增特征**；按与近期策略状态的接近程度对样本加权。

### 2.3 置信信号与确定性谓词

- 对目标样本 \(i\)，定义部署模型状态误差 \(e_i\)，以及运行中位数误差尺度 \(\tau_e\)。
- 一步置信目标 \(c_i = (1+e_i/\tau_e)^{-1}\)。
- 训练非正 **log-confidence critic** \(Q^\Delta_\xi\)，输入包含状态、动作以及路由相关集成的坐标标准差签名。
- 置信回归目标：
  - \(q_i^{\text{tgt}} = \log \max(c_i, 10^{-8}) + \gamma_\Delta (1-\kappa_i) Q^\Delta_{\bar{\xi}}(s_{i+1}, a^{\text{det}}_{i+1}, \sigma_{\text{ens}}(s_{i+1}, a^{\text{det}}_{i+1}))\)，其中 \(\gamma_\Delta=0.5\)。
- 想象转移权重：
  - \(w^\Delta_i = \exp(Q^\Delta_\xi(s_i,a_i,\sigma_{\text{ens}}(s_i,a_i))) \in (0,1]\)。
- 确定性谓词集合 \(C\) 包含形态特定表示、转移幅度、奖励范围检查；Walker 额外拒绝非有限预测。
- 最终信任权重 \(w_i = w^\Delta_i \chi_i\)，其中 \(\chi_i\) 为谓词通过指示；\(w_i \le 0.01\) 的样本丢弃。
- 论文强调：置信值是**学习到的排序信号，不是校准概率**；谓词只筛选想象转移，不约束目标动作，也不构成安全保证。

### 2.4 违规感知策略优化与检查点选择

- 每 250 个目标步，从 400 个目标回放状态出发，由部署模型生成一步想象转移。
- 物理奖励不乘置信权重；违规成本单独处理：
  - 二值违规指示 \(\iota_i\)；
  - 训练奖励 \(r_i^{\text{train}} = r_i - \lambda_v(t)\iota_i\)；
  - \(\lambda_v(t)\) 在前半程在线训练为 0，后半程线性升至 10。
- 策略评论家损失对想象转移用 \(w_i\) 加权，并加入三个评论家间的标准差惩罚（\(\lambda_{\text{ens}}=0.01\)）。
- 演员目标为评论家均值减两倍标准差加 SAC 熵项，另有 \(10^{-3}\) 行为克隆 MSE 惩罚。
- **演员路由**：初始模拟器到残差状态 RMSE 比率 \(\varrho_{\text{cal}}\) 决定演员更新是否混合目标与想象状态。
- **检查点恢复**：固定验证检查点可恢复满足违规预算的演员；验证被明确计为模型选择访问。
- 算法流程（Algorithm 1）：拟合冻结模拟器集成 → 划分数据 → 拟合残差与直接候选 → 计算风险与路由 → 锁定残差特征支持 → 初始化回放与置信评论家 → 在线循环中执行目标动作、定期重拟合部署模型、更新置信评论家、生成想象转移并计算信任权重、应用违规成本更新 SAC、定期验证并记录检查点 → 最后按规则恢复演员并一次性测试。

## 3. 实验设计

### 3.1 场景与 Benchmark

- 使用 MuJoCo 物理引擎（Gymnasium 1.2.0 v5 任务），构建三个受控模拟器到目标的动力学偏移：
  - **Ant actuator**：8 个主动动作 → 动作 4–7 禁用；计数违规为 \(|v_x|>1.5\) 或后墙碰撞。
  - **HalfCheetah gravity**：垂直重力 \(-19.62 \to -9.81\)；计数违规为 \(q_z>0.2\)。
  - **Walker friction**：摩擦因子 \(0.3 \to 1.0\)；计数违规为 \(s(0)>1.25\)。
- 每个模拟器–目标对保留任务形态、观测与动作维度，只改变一个受控动力学因素。
- 论文明确这些是**模拟器到模拟器实验**，不是物理 sim-to-real 部署。

### 3.2 对比方法

- **Calibration-routed MC-WM**：完整候选。
- **Residual MC-WM core**：保留稀疏+神经残差、置信评论家、策略感知重拟合，但固定残差部署，移除自适应更新路由、违规成本与验证检查点恢复。
- **Direct target MBPO**：相同概率世界模型架构直接拟合目标转移，一步 rollout。
- **Target SAC**：无学习世界模型，仅从目标转移学习。
- **Matched DARC**：匹配协议的 DARC 实现，使用状态–动作与状态–动作–下一状态分类器，32 单元隐藏层，单位高斯输入噪声，4,000 步后开始奖励校正。
- **Raw simulator SAC**：在未修正模拟器中训练 50,000 交互，无目标域训练转移。
