## 摘要
对相机和物体运动的精确控制对于专业视频制作至关重要。现有方法只能对物体进行粗略控制：要么通过图像平面线索，这些线索在深度和旋转方面存在歧义；要么通过缺乏完整几何信息、并在视角变化时失去一致性的3D轨迹和团块。我们提出4Director，一种以显式4D场景表示为条件的视频世界模型：每个物体从输入图像中一次性重建为规范网格，并在每帧中通过一个指定的刚性变换进行移动。这种表示提供了直观的3D控制界面，并防止未观测到的几何在每一帧中被独立重新生成。我们将受控场景渲染为深度视频，并引入Motion Adapter，将该几何支架转化为视频，同时合成视角一致的外观、光照和非刚性动态。为了训练，我们构建了RealCOD-Rigid，这是一个包含20,774个片段的新数据集，由我们的自动流程标注了刚性3D场景。我们进一步引入Identity-Gated IoU（IG-IoU），它联合评估对指定物体运动的遵循程度以及对物体身份的保持程度。实验表明，4Director在视觉质量以及相机和物体控制方面持续优于先前方法。

## Abstract
Precise control over camera and object motion is essential for professional video production. Existing methods control objects only coarsely, through image-plane cues that are ambiguous in depth and rotation or through 3D tracks and blobs that lack complete geometry and lose consistency across viewpoint changes. We introduce 4Director, a video world model conditioned on an explicit 4D scene representation: each object is reconstructed once from the input image as a canonical mesh and moved by one prescribed rigid transformation per frame. This representation provides an intuitive 3D control interface and prevents unobserved geometry from being regenerated independently in every frame. We render the controlled scene as a depth video and introduce a Motion Adapter that transforms this geometric scaffold into video while synthesizing view-consistent appearance, illumination, and non-rigid dynamics. For training, we construct RealCOD-Rigid, a new dataset of 20,774 clips annotated with rigid 3D scenes by our automatic pipeline. We further introduce Identity-Gated IoU (IG-IoU), which jointly evaluates adherence to prescribed object motion and preservation of object identity. Experiments demonstrate that 4Director consistently outperforms prior methods in visual quality and in camera and object control.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究动机**：专业视频制作中，导演需要精确指定相机与每个物体的运动轨迹，而把"如何走路""光如何落"留给生成器。现有视频世界模型无法提供这种级别的控制。
- **现有控制方式的两类缺陷**：
  - **图像平面线索**（拖拽路径、2D 框、掩码、点轨迹）：一个投影对应多种 3D 运动，深度与旋转存在歧义——框无法确定物体朝向，缩小框无法区分"远离"与"变小"，2D 路径混淆相机视差与物体运动。
  - **3D 感知控制**（刚性轨迹、3D 框、提升的点/球/高斯团块代理）：几何不完整。轨迹或框没有表面；提升代理只捕获可见外壳，转向或新视角揭示的几何不存在；点基代理还需逐点编写轨迹，作者负担重。
- **整体含义**：论文提出以**显式 4D 场景表示**作为视频生成条件，将"几何控制"与"外观/光照/非刚性动态合成"解耦，从而在单一坐标框架下同时精确控制相机与每个物体的刚体运动，并避免未观测几何被逐帧独立重新生成。

## 2. 方法论

### 2.1 核心思想
- 每个物体从输入图像**一次性重建为完整规范网格**（canonical mesh），每帧仅由一个 **SE(3) 刚性变换**驱动；背景点云、物体网格与相机共享同一坐标系。
- 场景渲染为**深度视频**作为控制信号，由一个可训练的 **Motion Adapter** 注入预训练视频生成器，由生成器补全渲染所缺失的外观、光照、非刚性动态与相机移动后新暴露的背景。

### 2.2 刚性 3D 几何控制（Sec. 3.1）
- **图像提升到 3D**：
  - MoGe-2 估计深度与内参 K；SAM 2 将用户点击转为物体掩码。
  - 输入图像相机定义参考帧（E₁ 为单位矩阵）。
  - 背景（掩码之外）反投影为静态点云 P；每个被标记物体由 **Pixal3D** 重建为完整规范网格 Mₒ，并与掩码、深度对齐。
- **轨迹定义**：用户在 3D 查看器中以关键帧指定轨迹。物体 o 以 Tₒᵗ = (Rₒᵗ, tₒᵗ) 整体移动，Tₒ¹ 为单位变换，第 t 帧的放置网格为
  - **Mₒᵗ = { Rₒᵗ v + tₒᵗ | v ∈ Mₒ }**
- **场景元组**：S = (P, {Mₒ}, {Tₒᵗ}, K, {Eₜ})，其中 P、网格、K 恒定，仅轨迹与相机随时间变化。
- **新物体插入**：从另一张图像重建网格并赋予轨迹，其带纹理网格渲染进输入图像作为首帧。
- **深度渲染**：每帧将 P 与放置网格按 (K, Eₜ) 投影为深度图，每像素取最近表面深度，无几何处为空。编码为 8-bit 灰度（近=255，远=0，无效=128），深度区间 [α, β] 按实体在所有帧上 1/Z 的 1%/99% 分位包络确定，保证同一深度在所有帧映射到同一灰度。

### 2.3 Motion Adapter（Sec. 3.2）
- **架构**：基于 **Wan2.1-VACE-14B**（latent video diffusion transformer），VAE、umT5 文本编码器与 DiT 主干保持不变。Motion Adapter 为 DiT 风格分支，采用 VACE 的 context-branch 设计：VAE 编码深度控制视频 C 与输入图像为 context 流，**8 个 context blocks（每 5 个 DiT 块一个）**通过 cross-attention 传播 prompt 并以线性投影 hint 注入 DiT。
- **训练信号设计**：每个训练对由同一原始片段构造——从恢复的刚性 3D 场景渲染的控制视频为条件，原片段为生成目标，其首帧为输入图像，文本描述为 prompt。控制视频**只含刚性运动**。物体表面点 Xᵢᵗ = Rₒᵗ Yᵢ + tₒᵗ + rᵢᵗ，其中前两项进入控制，残差 rᵢᵗ（如摆动的肢体）留给生成器。
- **损失**：标准 flow-matching 目标。设 z 为片段 latent，zₖ = (1−σₖ)z + σₖϵ 为加噪版本，模型从 zₖ、C、图像与 prompt 预测速度 ν，最小化
  - **E[ λₖ ‖ν(zₖ, k; C) − (ϵ − z)‖²₂ ]**
- **推理**：用户构建的场景渲染为控制视频 C，适配器从 C、图像与 prompt 生成视频。由于适配器只"看到"深度视频，新轨迹与新插入物体**无需额外训练**。

### 2.4 RealCOD-Rigid 数据集自动标注流程（Sec. 4）
四阶段，从 RealCOD-25K 的 25,318 个片段（81 帧、832×480、16fps，含文本与 SAM3 掩码）出发：
1. **相机与深度估计**：MegaSaM（MoGe-2 作深度先验、UniDepthV2 作度量分支）估计逐帧深度、内参 K 与相机轨迹；首帧背景反投影为点云 P（去除物体掩码）。
2. **首帧到 3D**：Pixal3D 从首帧物体裁剪重建规范网格 Mₒ；因像素对齐，用 Umeyama 闭式相似变换（旋转、平移、尺度）将网格对齐到 t=1 的物体，定义 Tₒ¹ 为单位变换；含 3D 门控（残差中位数≤0.15、p90≤0.30、p95≤0.50，按物体直径归一）与轮廓门控（IoU≥0.5）。
3. **刚体跟踪**：TAPIP3D 在场景帧内跟踪物体 3D 点（每物体 8 个锚帧 × 128 个最远点查询 = 1024 条查询）。并非所有轨迹刚性运动（肢体摆动、漂移），因此通过"鲁棒拟合 + 内点选择"交替求解物体的**稳定核心 Ωₒ**，仅在核心上逐帧拟合
   - **(Rₒᵗ, tₒᵗ) = argmin Σ_{i∈Ωₒ} ρ(‖R Yᵢ + t − Xᵢᵗ‖)**，ρ 为 Tukey 鲁棒损失；核心须含至少 30 条轨迹。
4. **深度渲染**：按刚性变换放置网格即得片段的刚性 3D 场景，渲染得到控制视频。
- 通过所有阶段且不属于评估集的 20,774 个片段构成 **RealCOD-Rigid**。

### 2.5 Identity-Gated IoU（Sec. 5.2）
- 掩码 IoU 单独使用会奖励"位置正确但已非同一物体"的情况。IG-IoU 仅在身份保持的帧上累计掩码 IoU：
  - **Recognition rate = (1/N) Σ v_f**，**IG-IoU = (1/N) Σ v_f · MaskIoU_f**
- 在物体可见帧中均匀取 N=16 帧；身份门 v_f ∈ {0,1} 由视觉-语言裁判（Qwen3-VL）比较生成裁剪与参考裁剪给出；掩码来自 SAM3。失败帧计 0 但仍留在分母。
