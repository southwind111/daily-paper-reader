## 摘要
为人工智能体赋予空间智能，需要对动态三维世界有一个全面的生成式先验。我们提出世界运动模型（WMMs），通过稀疏的SE(3)位姿轨迹来捕捉“随时间推移，什么曾在何处、什么正在何处、什么将在何处”。WMMs基于这样一个观察：动态场景中的元素可以被一组刚性SE(3)轨迹很好地近似，这是一种用于4D建模的极简却富有表现力的基元。该表示将铰接物体、人体、手-物交互、分段刚性场景动力学、相机运动，甚至机器人状态与动作，统一到一个共享空间中。基于这一表示，我们将这些实体的联合分布建模为一个灵活的序列建模问题，并利用具有逐token噪声水平的流匹配。结合用于非序列条件化的上下文token机制，该公式支持在任意数量的实体和时间步之间进行任意到任意的边缘条件化。未来预测、运动填充、模型预测控制、逆运动学、跨具身重定向和策略学习等任务，都归结为在同一网络上应用不同的掩码。在3D视觉与机器人学的6个多样化应用上的实验表明，WMMs具有多功能性、灵活性，并取得强劲性能。

## Abstract
Equipping artificial agents with spatial intelligence requires a comprehensive generative prior over the dynamic 3D world. We propose World Motion Models (WMMs) that capture "what was, is, and will be where across time" via sparse SE(3) pose trajectories. WMMs are built on the observation that elements of dynamic scenes can be well approximated by a set of rigid SE(3) trajectories, a minimal yet expressive primitive for 4D modeling. This representation unifies articulated objects, human bodies, hand-object interactions, piecewise-rigid scene dynamics, camera motion, and even robot states and actions into a single shared space. Given this representation, we cast the joint distribution of these entities as a flexible sequence modeling problem, utilizing flow-matching with per-token noise levels. Coupled with a context token mechanism for non-sequential conditioning, this formulation supports any-to-any marginal conditioning across an arbitrary number of entities and time steps. Tasks such as future prediction, motion infilling, model-predictive control, inverse kinematics, cross-embodiment retargeting, and policy learning all reduce to the application of different masks over the same network. Experiments on 6 diverse applications of 3D vision and robotics demonstrate the versatility and flexibility of WMMs with strong performance.

- **现有方法的碎片化问题**：
  - 生成式运动模型按**行为体类别**分裂：人体、人-人交互、手-物交互、场景动力学各自使用专属状态参数化（SMPL、MANO、URDF 等），表示与类别绑定。
  - 统一路线多停留在**稠密观测空间**（像素对齐点轨迹、3D flow、视频），将 3D 运动与外观、光照、视角变化纠缠在一起。
  - 分段刚性的 SE(3) 方法（SE3-Nets、SPOT 等）仅限单智能体或固定物体集合。
- **核心洞察**：真实世界运动具有**低秩性**——复杂稠密场景变形可由少量特征刚性轨迹近似。人体/机器人上千顶点的稠密流可压缩为数十个关节的 SE(3) 轨迹；相机与刚体是单个运动帧；非刚性场景动态可表示为少量 SE(3) 基的插值。
- **整体含义**：以**稀疏 SE(3) 位姿轨迹**作为统一"运动语言"，将铰接物体、人体、手物交互、相机、机器人状态与动作统一到共享空间，从而用一个模型提供 4D 世界的通用生成先验。

## 2. 方法论

### 2.1 表示：运动建模的语言

- **基本单元（token）**：一个连续 token = 位姿 `T ∈ SE(3)`（"where"）+ 特征 `F ∈ R^D`（"what"）。
  - 特征 `F_i = [f_sem; f_geo]`：语义部分为 DINO 像素特征或可学习类别嵌入；几何部分为 PointNet 在局部点云上的描述子（无点云时可省略）。特征沿轨迹共享、不随时间变化。
- **位姿参数化**：9 维向量 `T = (x, x+δr1, x+δr2) ∈ R^9`，其中 `x` 为位置，`(r1,r2)` 为 6D 旋转参数化的前两列，`δ=0.2` 用于把扩散信号归一化到标准正态。
- **轨迹与场景**：实体 i 的轨迹 `τ_i = ([T_i^(l), T_i^(m), ...], F_i)`；动态场景 `X = {τ_i}` 即 M 条轨迹的集合。
- **上下文 token（Context Tokens）**：为支持非因果锚点（如远在 rollout 窗口之外的目标状态、跨具身重定向的配对示例），为每条轨迹增加一段"虚拟时间步"前缀，使用**独立的位置嵌入**；这些 token 在训练与推理中与真实轨迹 token 完全同等对待。
- **建模目标**：不是简单先验 `P(T|F,A)`，而是**任意边缘条件分布族**：
  - `P(T_unk | T_obs, F, A)`，对所有 `T_obs ⊂ T`，即对轨迹集合任意划分（观测子集 vs 补集）诱导的所有分布。

### 2.2 训练：逐 token 噪声水平的流匹配

- **核心思想**：把每个 6D SE(3) 位姿（某实体在某时刻）视为**独立 token**，各自分配独立噪声水平，在单次共享前向中联合去噪。受 Diffusion Forcing 与离散扩散（dLLM）启发。
- **前向过程**：给定干净轨迹 `T`（形状 `M×N×9`），逐 token 采样 `λ_{i,l} ~ U[0,1]` 与高斯噪声 `ε_{i,l} ~ N(0,I_9)`：
  - `T^(λ)_{i,l} = (1-λ_{i,l}) T_{i,l} + λ_{i,l} ε_{i,l}`
- **速度目标与损失**：模型 `M_θ` 为流匹配速度场，预测从干净位姿指向噪声的**速度**（注意论文原文为 `v* = ε - T`，即从干净指向噪声方向，并按此方向积分）：
  - `v*_{i,l} = ε_{i,l} - T_{i,l}`
  - `L(θ) = E_{T,Λ,ε} Σ_{i,l} || M_θ(T_Λ, F, A, Λ)_{i,l} - v*_{i,l} ||²`
- **为何单一目标足够**：每个随机 `Λ` 将 token 划分为近干净（类观测）与近噪声（类目标）两组，覆盖所有条件反向过程，确定性观测/目标划分是极限情形。可通过偏置噪声调度（如历史用小 λ、未来用大 λ）强化预测能力。

### 2.3 推理：同一网络导出多种边缘分布

- **操作方式**：用户指定观测/目标 mask，观测 token 置 `λ=0`，目标 token 置 `λ=1`，从 `λ=1` 积分到 `0` 得到 `P(T_unk|T_obs,F,A)` 的采样。
- **典型 mask 对应任务**：
  - (i) **未来预测/策略**：`l ≤ l0` 为 0，`l > l0` 为 1；仅状态实体→未来预测；含动作实体→机器人策略。
  - (ii) **动作条件前向动力学**：动作已知、未来状态未知→用于 MPC 的前向模拟器。
  - (iii) **运动规划/填充**：稀疏（可能部分）关键帧已知，其余为目标。
  - (iv) **重定向/伙伴预测/逆动力学**：按实体划分，已知一侧身体→跨具身重定向；已知手→手物伙伴预测；已知状态实体→逆动力学。
- **鲁棒性**：观测 token 的 λ 可设为小正值（如 0.05）而非 0，使观测成为"强提示"，积分过程中可轻微校正观测噪声。
- **超越训练预算的泛化**：RoPE 本身有助外推；提出**锚定滑窗稠密采样器**（Alg. 1）：用上一批部分去噪的 token 作为固定锚点（A 个），与 S−A 个新 token 一起按异步噪声水平推进，实现任意数量实体/时间步的全局一致生成。

### 2.4 架构实现

- **三大挑战的应对**：
  1. **逐 token 条件**：对每个 token `(i,l)` 拼接 λ 的正弦嵌入、特征 `F`、辅助条件 `A` 的池化嵌入，经逐块宽 MLP 映射为 AdaLN 的 scale/shift 参数。
  2. **规模**：M×N 网格（30 帧、400 轨迹即约 12K token）上使用**五类因式化注意力**：`a`（全 token 自注意力）、`t`/`p`（时间轴/实体轴自注意力）、`s`/`q`（对应轴上仅 register 的注意力，通道数大幅加宽、运行开销可忽略）。
  3. **缺失观测**：无效 token 固定为 `λ=1`（纯噪声）但仍参与注意力，损失只对有效标签 token 求和；虚拟上下文 token 用 1-bit 前缀掩码标记；文本/图像 token 作为注意力前缀。

  - Language Table B2B：去掉 AdaLN、去掉逐 token 噪声（改用同步噪声+引导式条件）。
  - TraceGen EpicKitchen：去掉高效 register 路径、退化为 plain DiT（去掉轴式因式化）。
  - 附录：旋转尺度 δ（0.2/0.6/1.0）、语义/几何特征消融、SMPL 与 G1 的参数化投影一致性、RGB→3D 轨迹的数据生成成本。

## 4. 资源与算力
