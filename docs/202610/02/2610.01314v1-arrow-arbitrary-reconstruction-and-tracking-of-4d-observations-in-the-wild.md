tldr: 动态场景可由运动相机、多段视频或不同时间图像捕获，观测间包含互补几何与运动信息，但跨视角、时间和可见性建立对应仍很困难。ARROW 是前馈模型，用顺序不变查询机制关联查询与任意输入观测，统一任意图像集的3D重建和3D点跟踪，并以多样化输入训练提升泛化能力。该方法在 WorldTrack 和 TAPVid-3D 上刷新3D跟踪SOTA，在适配RGB-only MVTracker基准上超越专用多视图跟踪器，重建任务也具竞争力。代码与权重公开。

## 摘要
动态场景可能由移动相机、多个视频流或不同时间拍摄的图像捕获。这些观测揭示了场景几何与运动的互补信息，但要将它们融合在一起，需要在不同视角、拍摄时间和可见性变化之间建立对应关系。我们提出 ARROW，一种前馈模型，可从任意图像集合中统一进行3D重建和3D点跟踪。其核心是一种新颖的顺序不变查询方法，允许在任意输入上将查询与观测关联起来。我们表明，在训练期间让模型接触更多样化的输入集合可提升任务性能。此外，所得模型能够泛化到更广泛的任务，包括多视图跟踪。采用该策略训练后，ARROW 在 WorldTrack 和 TAPVid-3D 上建立了3D跟踪的新技术最优，并在适配的仅RGB MVTracker基准上优于专用多视图跟踪器，同时在各类3D重建任务上保持竞争力。代码与权重已公开。

## Abstract
Dynamic scenes may be captured by a moving camera, multiple video streams, or images taken at different times. These observations reveal complementary aspects of scene geometry and motion, yet bringing them together requires establishing correspondence across viewpoints, capture times, and visibility changes. We introduce ARROW, a feed-forward model that unifies 3D reconstruction and 3D point tracking from arbitrary image sets. At its core is a novel order-invariant querying approach, which allows the association of queries with observations across arbitrary inputs. We show that exposing the model to more diverse sets of inputs during training results in improved task performance. Moreover, the resulting model is capable of generalization to a wider range of tasks including multi-view tracking. Trained with this strategy, ARROW establishes a new state of the art in 3D tracking on WorldTrack and TAPVid-3D and outperforms dedicated multi-view trackers on an adapted RGB-only MVTracker benchmark, while remaining competitive across 3D reconstruction tasks. Code and weights are publicly available.

- **整体含义**：论文提出 **ARROW**，将“任意观测集”作为一等公民，统一 3D 重建与 3D 点跟踪。其核心洞见是：**用内容派生的身份（ID token）替代顺序相关的时间嵌入**，从而在无顺序的输入上实现查询与观测的关联。论文还表明，让模型在训练中接触更广泛的输入分布（静态图像集、动态视频、多视图序列）能反过来提升跟踪本身的性能，并泛化到多视图跟踪等更广任务。

## 2. 论文提出的方法论

### 2.1 核心思想
- **查询公式**：一个查询定义为四元组 `q = (u, v, i_src, i_tgt, i_ref)`，其中 `(u,v)` 是源观测中的像素坐标，`i_src/i_tgt/i_ref` 分别指定源、目标、参考观测的索引。目标是输出该物理点在**目标观测拍摄时刻**、**参考观测坐标系**下的 3D 位置。该接口可推导出轨迹、点云、相机参数等多种输出。
- **顺序不变查询**：D4RT 依赖序列位置编码建立查询与观测的关联（图 2a）；若直接换成无顺序的图像集编码器，查询嵌入与上下文特征将失去匹配依据（图 2b）。ARROW 的解法是**利用内容派生的 ID token**（图 2c）：ID token 与全局上下文处于同一嵌入空间，且与帧位置无关，从而实现顺序不变的关联。

### 2.2 关键技术细节

**（1）多视图编码器**
- 以 **DA3（Depth Anything 3）** 初始化，这是一个交替进行帧内自注意力与全局自注意力的 ViT，预训练于多视图图像集。
- 输出全局上下文 `F ∈ R^{N×C}` 以及每个观测一个 ID token `h_i ∈ R^C`：`(F, {h_i}) = E(I)`。
- **复用 DA3 的 camera token 作为 ID token**，但不对其作相机估计解释，也不与后续位姿恢复绑定。
- 输入被视为顺序无关的集合，**不添加任何时间编码**。

**（2）查询编码器**
- 将查询编码为潜在查询 token `z_q`：
  `z_q = φ_rgb(I_{i_src}, u, v) + φ_uv(u, v) + φ_rel([h_{i_src}; h_{i_tgt}; h_{i_ref}])`
  - `φ_rgb`：嵌入以源点为中心的 9×9 RGB 裁剪块；
  - `φ_uv`：嵌入傅里叶编码的归一化坐标 `2(u,v)-1 ∈ [-1,1]²`；
  - `φ_rel`：将源–目标–参考顺序拼接的 ID token 投影到解码器维度；
  - 三者均为两层 MLP。
- 像素中心归一化为 `u=(x+1/2)/W`、`v=(y+1/2)/H`，这种相对位置参数化支持不同长宽比的矩形输入。

**（3）稀疏解码器**
- 每个查询 token **独立**对全局上下文 `F` 做交叉注意力，**查询之间无自注意力**。
- 输出：3D 位置 `x̂`、置信度 `ĉ`、目标图像坐标 `(û,v̂)`、可见性 logit `ô`、单位表面法线 `n̂`、源到目标位移 `d̂`。所有量均在目标观测拍摄时刻预测；3D 量在参考观测坐标系下表达。
- 由于查询相互独立，一次编码可复用于稀疏查询与稠密解码。

### 2.3 训练策略
- **三类数据机制**：
  1. **静态场景**：已知几何提供平凡对应（点不动，外观与相机坐标变化）；
  2. **带轨迹的动态场景**：标注轨迹提供跨时间对应与运动监督，静态背景提供锚点；
  3. **无轨迹的动态场景**（如 nuScenes）：限制 `i_tgt = i_src`，只做几何监督，避免错误运动监督。
- **非顺序采样**：跨相机视角、跨非局部时间邻域采样观测，候选时间窗口可达所需集合的 10 倍；多视图数据集可贡献同一场景的不同相机。
- **损失函数**（多任务，各项仅在目标有效处施加）：
  `L = λ_3D L_3D + λ_conf L_conf + λ_uv L_uv + λ_vis L_vis + λ_normal L_normal + λ_disp L_disp`
  - `L_3D`：尺度不变、置信度加权的 ℓ1 损失；
  - `L_conf = -mean log ĉ` 正则化置信度；
  - 其余为 UV、位移 ℓ1 损失，可见性二元交叉熵，法线余弦距离；
  - 权重：λ_3D=1, λ_conf=0.2, λ_uv=0.1, λ_vis=0.1, λ_normal=0.5, λ_disp=0.1。
  - 目标与预测各自按到参考相机原点的平均欧氏距离归一化，并施加逐元素带符号对数变换，消除全局尺度歧义。
- **采样细节**：对深度/法线不连续处过采样（30% 几何预算在边缘 3 像素内），对运动边界静态侧高斯加权采样（避免背景随物体变形），并按数据集配置轨迹/边界/动态/几何查询比例。

## 6. 主要结论与发现

- **统一接口可行且有效**：以四元组查询 `(u, v, i_src, i_tgt, i_ref)` 为唯一接口，单一模型即可同时产出轨迹、点云、相机位姿、深度、法线、位移等多种输出，验证了几何与跟踪统一建模的可行性。
- **顺序不变性是关键**：用内容派生的 ID token 替代位置/时间嵌入后，模型可直接处理无固有顺序的观测集；消融显示，移除编码器时间嵌入（S3）并未损害甚至提升了任意观测集上的性能，说明对顺序的强加是不必要的归纳偏置。
- **非顺序采样与静态数据带来正迁移**：加入非顺序采样（S4）与静态多视图数据集（S5）不仅改善了重建/位姿，还**反过来提升了跟踪性能**，支持“更广输入分布有益于跟踪本身”的核心主张。
- **长上下文推理优于窗口推理**：在全序列上下文下推理比滑动窗口拼接更准确，说明全局注意力对维持跨时间点身份一致性有实质作用。
- **多视图跟踪可泛化**：尽管训练中未显式针对多视图同步序列优化，模型在适配版 MVTracker 上仍具竞争力，表明 ID 条件机制能自然迁移到多相机同步场景。
- **短上下文不退化**：24 帧短上下文消融表明，支持任意观测集并未以牺牲常规短视频性能为代价。

## 7. 优点与局限

**优点**
- **问题定义清晰且具一般性**：将“任意观测集”作为一等公民，统一了单目视频、多视图序列与静态图像集三类此前分立的问题设定。
- **方法简洁、归纳偏置合理**：核心改动仅是用 ID token 替换顺序嵌入，却从根本上解决了无序输入的关联问题，改动小、收益大、易理解。
- **接口表达力强**：单一查询接口可推导多种下游输出，避免了为每个任务单独设计头或流程。
- **训练数据与采样策略设计细致**：三类数据机制、非顺序采样、边缘/运动边界过采样等，均针对任务特性做了有依据的工程处理。
- **实验覆盖广、消融链条完整**：6 类任务、约 10 个基准、累计消融逐步隔离变量，论证结构清晰。

**局限**
- **算力门槛高**：32 张 GH200、200k 步训练，复现成本对多数研究者而言较高。
- **依赖大规模多视图预训练骨干**：以 DA3 初始化是性能的重要前提，方法在无此预训练时的表现未充分探讨。
- **部分任务仍依赖辅助监督**：法线、可见性、位移等辅助头与损失虽提升性能，但也增加了训练复杂度与超参调优负担。
- **自建基准的绝对可比性有限**：多视图跟踪适配版与官方协议不可直接数值比较，削弱了“SOTA”声明的力度。
- **未充分讨论失效情形**：如强遮挡、快速运动、极端视角变化、透明/反光表面等困难场景下的行为缺乏系统性分析。
- **ID token 的语义未深入剖析**：论文明确不将 camera token 解释为相机估计，但 ID token 究竟编码了何种身份信息、其容量与稳定性如何，缺乏可视化或理论层面的进一步探究。

## 8. 对领域的影响与启示

- 论文提示：**顺序并非关联的必要条件**，内容派生的身份表征足以支撑跨视角、跨时间的对应，这对未来统一 3D 感知模型的设计具有方法论意义。
- 将重建与跟踪视为同一查询接口下的两个侧面，可能推动后续工作进一步合并深度、位姿、光流、分割等任务到统一表示中。
- “训练分布更广 → 跟踪更强”的发现，暗示点跟踪的瓶颈部分来自数据多样性而非模型容量，为数据侧研究提供了方向。
