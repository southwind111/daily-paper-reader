## 摘要
近期诸如 Depth Anything 3（DA3）等深度基础模型实现了出色的多视图深度估计，但其假设场景为静态3D场景，限制了其在真实动态环境中的适用性。现有的免训练4D方法（如 Easi3R 和 VGGT4D）依赖经对应关系训练的骨干网络，其注意力机制编码了跨帧匹配信息，而这一特性在 DA3 等仅做深度的模型中并不存在。我们提出 Dyna3，一个免训练框架，无需任何微调即可将 DA3 扩展至4D动态场景重建。我们的关键洞察是：DA3 的跨视图特征虽仅针对深度一致性训练，但当与跨帧最佳匹配特征搜索相结合时，会隐式编码具有运动判别性的信号。其静态表面可在全局找到一致匹配，而动态物体则不能。我们进一步采用视觉语言模型（VLM）自动生成面向具体场景的语义提示，用于 SAM 3，从而实现精确的实例级分割，以区分哪些物体在运动以及场景中存在哪些物体。在重建方面，我们将场景解耦为跨帧对齐的静态背景与逐帧动态点云。在四个数据集上的实验表明，Dyna3 在动态物体分割上以 +5.5pp 的 J-Mean 超越经对应关系训练的方法，优于当前最优的 VGGT4D；同时位姿估计最高快 13 倍，4D 重建快 3 倍，内存占用降低 4 至 8 倍。因此，Dyna3 能够支持此前方法无法实现的更密集时间采样。

## Abstract
Recent depth foundation models like Depth Anything 3 (DA3) achieve remarkable multi-view depth estimation but assume static 3D scenes, limiting their applicability to real-world dynamic environments. Existing training-free 4D methods like Easi3R and VGGT4D rely on correspondence-trained backbones whose attention encodes cross-frame matching, a property absent in depth-only models like DA3. We present Dyna3, a training-free framework that extends DA3 for 4D dynamic scene reconstruction without any fine-tuning. Our key insight is that DA3's cross-view features, though trained only for depth consistency, implicitly encode motion-discriminative signals when combined with best-match feature search across frames. Its static surfaces find consistent matches globally, while dynamic objects cannot. We further adopt vision-language models (VLM) to automatically generate scene-specific semantic prompts for SAM 3, enabling precise instance-level segmentation that distinguishes which objects move from what objects exist. For reconstruction, we decouple the scene into a cross-frame aligned static background and per-frame dynamic point clouds. Experiments on four datasets demonstrate that Dyna3 surpasses correspondence-trained methods with +5.5pp J-Mean over state-of-the-art VGGT4D on dynamic object segmentation, while achieving up to 13x faster pose estimation and 3x faster 4D reconstruction with 4 to 8x lower memory. Dyna3 could therefore enable much denser temporal sampling that prior methods cannot support.

## 2. 方法论：核心思想与关键技术

- **总体流程**：输入单目视频，输出静态背景点云、逐帧动态点云和相机位姿；全程推理时运行，不修改 DA3 权重或架构。
- **DA3 几何提取**：
  - 从 DA3 获得每帧深度 \(D_i\)、射线图、patch 特征 \(F_i\)，并通过 RANSAC 分解射线图得到外参 \(E_i\) 和内参 \(K_i\)。
  - 每个像素通过反投影得到世界坐标 \(X_i(u)\)。
- **最佳匹配特征搜索运动检测**：
  - 对帧 \(i\) 中位置 \(u\)，在时间邻域 \(N_i\) 的邻帧中全局搜索最相似特征，用余弦相似度衡量。
  - 运动分数定义为：
    \[
    S_i(u)=1-\frac{1}{|N_i|}\sum_{j\in N_i}\max_{u'\in\Omega_j}\frac{\langle f_i(u),f_j(u')\rangle}{\|f_i(u)\|\|f_j(u')\|}
    \]
  - 静态表面即使因相机运动位移，也能在邻帧找到一致匹配，分数低；动态物体难以找到一致匹配，分数高。
  - 对 \(S_i\) 逐帧归一化、按 75 百分位阈值二值化，并保留最大连通域，得到粗运动先验 \(\Phi_i\)。
- **VLM 引导实例分割**：
  - 从运动先验提取 bounding box，裁剪代表帧，送入 VLM。
  - VLM 被要求输出 **1–3 个具体名词短语**，如 “cyclist”“dog”，而不是泛化类别 “person”“object”。
  - 这些场景特定提示驱动 **SAM 3** 生成候选实例掩码 \(M_i^{c,k}\)。
  - 实现上缓存 SAM3 视频特征，复用给多个 prompt，获得约 **4×** 加速。
- **运动感知动态实例选择**：
  - 对每个候选实例掩码，计算其内部运动分数均值：
    \[
    \mu(k)=\mathrm{mean}_{u\in M_i^k} S_i(u)
    \]
  - \(\mu(k)>\theta\) 的实例判为动态；若全部低于阈值，选最高者，保证至少识别一个动态对象。
  - 合并后得到每帧动态掩码 \(M_i\)，解决“同一类别中既有运动也有静止实例”的歧义。
- **解耦式 4D 重建**：
  - **静态背景**：排除动态区域，并将动态掩码膨胀 \(\delta\) 像素以避免边界泄漏；多帧非动态像素反投影后体素下采样合并为统一静态点云。
  - **动态前景**：每帧动态像素单独形成点云 \(X_i^{dyn}\)，不跨帧合并

- **动态前景（续）**：动态点云不跨帧合并，因此每个动态实例在每一帧都保留独立的几何表示，避免因物体运动导致的错误融合；静态背景与动态前景在输出时按帧拼接，形成逐帧一致的 4D 点云序列。
- **相机位姿与坐标系对齐**：直接复用 DA3 由射线图 RANSAC 分解得到的外参 \(E_i\) 与内参 \(K_i\)，并以此作为统一世界坐标系，保证静态背景与动态前景处于同一几何框架下，无需额外优化或全局 BA。
- **推理流程总结**：单次前向完成 DA3 几何提取 → 特征匹配运动检测 → VLM 生成场景特定 prompt → SAM3 实例分割 → 运动分数筛选 → 解耦式 4D 点云输出；全程无需训练、无需人工标注，且可处理任意长度视频的滑动窗口推理。

## 3. 实验设计与评估

- **任务与指标**：
  - 动态对象分割：采用 Jaccard 平均（J-Mean）与 mIoU，评估运动掩码与真值的一致性。
  - 4D 重建：报告深度误差、点云精度与相机位姿误差，并在定性结果中展示动态点云分离效果。
  - 效率：对比推理时间、显存占用与 SAM3 prompt 复用带来的加速。
- **数据集**：在包含明显动态对象的单目视频基准上评估，覆盖人物、动物、车辆等多类运动场景，并设置与静态场景对照的消融。
- **对比方法**：
  - 免训练 4D 方法：Easi3R、VGGT4D 等基于对应关系主干的方案。
  - 深度/几何基础模型：DA3 直接迁移版本、DUSt3R、MonST3R 等。
  - 分割基线：仅用运动先验、仅用 SAM3、以及不同 VLM prompt 策略。
- **关键结果**：
  - 直接套用 DA3 注意力做运动检测仅约 **8% J-Mean**；Dyna3 通过显式跨帧特征比较将 J-Mean 显著提升，接近或超过对应关系训练主干的免训练方法。
  - 在保持 DA3 效率优势的前提下，动态分割与 4D 重建质量具有竞争力，且 SAM3 特征缓存带来约 **4×** 加速。
  - 消融显示：最佳匹配特征搜索、VLM 场景特定 prompt、运动感知实例选择三者缺一不可；仅用粗运动先验会导致静止实例误判，仅用语义分割会漏掉未命名运动物体。

## 4. 主要贡献与创新点

- **首个纯深度基础模型的免训练 4D 重建框架**：证明不依赖对应关系监督的 DA3 也能通过显式跨帧特征比较挖掘运动线索，拓展了深度基础模型在动态场景中的适用边界。
- **最佳匹配特征搜索运动检测**：用余弦相似度在时间邻域全局搜索最相似特征，构造对相机运动鲁棒、对物体运动敏感的运动分数，替代不可用的注意力运动先验。
- **VLM + SAM3 语义引导与运动感知实例选择**：用 VLM 生成场景特定名词短语驱动 SAM3，再用运动分数均值筛选动态实例，解决“同类中动静混合”的歧义，并保证至少识别一个动态对象。
- **解耦式 4D 重建与工程优化**：静态背景多帧融合、动态前景逐帧独立，配合动态掩码膨胀避免边界泄漏；SAM3 特征缓存复用显著降低推理成本。

## 5. 局限性与未来方向

- **对 DA3 几何质量的依赖**：深度与射线预测误差会直接传播到运动分数与点云，弱纹理、透明或反射表面可能产生噪声。
- **运动检测的阈值敏感性**：75 百分位阈值、连通域保留与实例选择阈值 \(\theta\) 需针对场景调整，快速运动或小物体可能被漏检。
- **语义先验的覆盖范围**：VLM 提示若未覆盖某些运动物体，SAM3 无法生成对应掩码，依赖运动先验的兜底策略。
- **动态前景不跨帧合并**：虽避免错误融合，但缺乏跨帧动态对象关联，难以直接输出带身份跟踪的 4D 轨迹。
- **未来方向**：引入轻量跨帧关联实现动态实例跟踪、自适应阈值与在线校准、结合视频扩散或时序先验提升遮挡与快速运动鲁棒性，并探索在 DA3 上做参数高效微调以进一步增强运动敏感性。

## 6. 总体评价

Dyna3 的核心价值在于重新审视了“深度基础模型能否做 4D”这一被默认否定或忽视的问题，并给出肯定且实用的答案。它没有改造 DA3 的架构或训练目标，而是通过显式跨帧特征比较、VLM/SAM3 语义引导和运动感知筛选，把纯深度模型转化为免训练 4D 重建系统，在效率与动态分割质量之间取得良好平衡。其方法论对后续“非对应关系主干 + 动态场景”的研究具有启发意义，也提示了基础模型能力边界可通过推理时组合而非重训练来拓展。
