## 摘要
我们提出 ProDyGS，一种新颖的动态 3D 高斯泼溅框架，用于从单个静态相机拍摄的视频中实现高质量的新视角合成。现有方法依赖多视角设置或显著的相机运动来提供几何约束，而我们的方法面向多视角监督完全缺失的挑战性场景。我们通过深度引导的代理图像合成来生成合成的多视角监督，从而克服这一限制。具体而言，我们使用基础单目深度网络估计时间上一致的深度图，然后构建 3D 高斯表示，以从任意视角生成代理图像。变形网络利用这种增强监督，通过对规范高斯进行变形来学习时间动态。在 DyNeRF 数据集上的实验表明，我们的方法在仅需要单目深度估计作为外部监督的情况下达到了最先进的性能，优于依赖场景流等更强先验的方法。

## Abstract
We present ProDyGS, a novel dynamic 3D Gaussian Splatting framework for high-quality novel view synthesis from videos captured by a single static camera. While existing methods rely on multi-view setups or significant camera motion for geometric constraints, our approach addresses the challenging scenario where multi-view supervision is completely absent. We overcome this limitation by generating synthetic multi-view supervision through depth-guided proxy image synthesis. Specifically, we estimate temporally consistent depth maps using foundational monocular depth networks, then construct 3D Gaussian representations that generate proxy images from arbitrary viewpoints. A deformation network learns temporal dynamics by warping canonical Gaussians using this augmented supervision. Experiments on the DyNeRF dataset demonstrate that our method achieves state-of-the-art performance while requiring only monocular depth estimation as external supervision, outperforming approaches that rely on stronger priors such as scene flow.

## 一、核心问题与研究动机

- **任务定位**：动态新视角合成（Dynamic View Synthesis, DVS）/ 4D 新视角合成，目标是从视频中重建可任意视角、任意时刻渲染的动态 3D 场景。
- **背景现状**：NeRF 与 3D Gaussian Splatting（3DGS）及其动态扩展（如 D-NeRF、Nerfies、4DGS、Deformable GS 等）高度依赖**多视角几何约束**——即需要多相机同步采集，或单目相机具备足够大的运动（teleporting camera motion）来提供视差。
- **核心痛点**：在**单台静态单目相机**拍摄的日常视频中（相机缓慢平滑移动甚至完全静止），多视角监督**完全缺失**，现有 DVS 方法渲染质量急剧下降。
- **已有路线的不足**：部分工作（如 MoDGS）转而依赖更强的外部先验（预计算深度、光流、场景流）来补偿，但作者认为这**回避了真正的问题**——缺少的是引导训练的多视角几何约束本身。
- **本文主张**：不再堆叠更强的先验，而是**主动"恢复"缺失的多视角监督**，通过深度引导的代理图像合成，为训练注入合成的多视角几何约束。

## 二、方法论

### 2.1 核心思想

以**深度**为中枢模态：对每一帧估计时序一致的深度图，用深度把单目图像"前向投影"到一组围绕原相机的虚拟视角，生成**代理图像（proxy images）**，从而人为构造出多视角训练集，再以 3DGS + 变形网络的 4D 表示进行监督学习。

### 2.2 第一阶段：深度估计与精炼

- **单目深度估计**：使用预训练基础模型 Φ（选用 **Depth Pro**）为每帧 $I^0_i$ 预测深度图 $D^0_i$；选择理由是其推理速度快、边缘对齐好（尽管偏平滑）。
- **神经精炼**：用第二个模型 Ψ（**Neural Disparity Refinement** 框架）对 $(I^0_i, D^0_i)$ 做连续输出形式的精炼，得到 $\hat{D}^0_i$，提升深度精度与锐度。
- **时序一致性（尺度漂移校正）**：
  - 用 **SEA-RAFT** 计算各帧与首帧 $I_0$ 的光流，分离**静态背景掩码** $B^0_i$；
  - 仅在静态背景区域上求解尺度 $\alpha_i$ 与偏移 $\beta_i$，最小化 $\left\|\alpha B^0_i \hat{D}^0_i + \beta - B^0_i \hat{D}^0_0\right\|^2$；
  - 得到对齐后深度 $\dot{D}^0_i = \alpha_i \hat{D}^0_i + \beta_i$。
  - 直觉：静态相机下背景深度随时间不变，可作为全局尺度基准。

### 2.3 第二阶段：代理图像生成

- 固定真实相机位姿 $\Pi^0$（可取单位阵或任意位姿），在场景周围**前半球配置**采样 $M$ 个虚拟相机位姿 $\{\Pi^j\}_{j=1}^{M}$。
- 对每一帧 $(I^0_i, \dot{D}^0_i)$：
  - 以每个像素的 3D 坐标为高斯基元中心、以原图像素颜色初始化颜色，构建一个**轻量 3DGS 模型** $G_i$；
  - 仅优化约 **100 步**，随后通过可微泼溅 $S(\Pi^j, G_i)$ 从各虚拟视角渲染代理图像 $\{I^j_i\}$；
  - 渲染时按深度排序，用 $\alpha$ 混合公式合成像素颜色。
- **轻量 3DGS 用完即弃**，只保留采样位姿与代理图像，用于后续 ProDyGS 优化。

### 2.4 第三阶段：ProDyGS 4D 表示

- 沿用 **4D Gaussian Splatting** 范式：一组位于规范空间的 3D 高斯基元 $G$ + 一个变形网络 $\Omega$。
- 渲染形式：$\hat{I}^j_i = S(\Pi^j, G'_i)$，其中 $G'_i = G + \Delta_i G$，$\Delta_i G = \Omega(G, i)$。
- **时空编码器**：多分辨率 **HexPlane** 表示（六个平面 $(x,y),(x,z),(y,z),(x,t),(y,t),(z,t)$，两个空间尺度）+ 轻量 MLP，将 4D 坐标编码为特征。
- **多头解码器**：五个浅层 MLP 分支分别预测位置、尺度、旋转、不透明度、颜色的逐高斯基元增量 $\{\phi_x, \phi_s, \phi_r, \phi_o, \phi_c\}$，叠加到规范高斯上得到 $G'_i$。

### 2.5 损失函数

- 总损失：$\mathcal{L} = \mathcal{L}_{rgb} + \mathcal{L}_{depth} + \mathcal{L}_{reg}$。
- **RGB 损失**：L1 + SSIM 加权组合，**仅在渲染图像的可见区域**计算。
- **深度损失**：尺度/偏移不变（SSI）形式，将预测深度 $\hat{D}_i$ 与对齐后的代理深度 $\dot{D}^0_i$ 比较，使用鲁棒 L2。
- **正则项**：对 HexPlane 特征网格施加基于网格的**全变分（TV）**正则，抑制退化解、稳定训练。

## 六、主要结论与发现

- ProDyGS 在 DyNeRF 上**全面超越**所有对比方法，且在所有指标上一致领先。
- 平均结果：**PSNR 26.64 / SSIM 0.8806 / LPIPS 0.1110**，对比次优方法 MoDGS 的 22.64 / 0.8042 / 0.1545，**PSNR 平均提升约 4 dB**；单场景最大提升超过 **6 dB**（sear steak）。
- 仅需**单目深度估计**这一种外部先验，即可超过依赖**场景流**等更强先验的 MoDGS，说明"恢复多视角监督"比"叠加更强先验"更有效。
- 消融结论：
  - 仅 2 个代理视角即可获得较高质量；增至 **4 个**时提升显著；继续增加到 8/18 个收益递减（边际效应）。
  - 深度精炼阶段贡献相对较小，但能显著改善**深度不连续处**的边缘清晰度与高频细节。

## 七、优点

- **问题切入角度新颖**：不依赖更强先验，而是直接针对"多视角监督缺失"这一根本矛盾，用深度引导的代理图像合成"补回"监督信号，思路简洁、动机自洽。
- **方法与工程轻量**：代理图像生成阶段只用 100 步优化的轻量 3DGS，用完即弃，开销可控；主框架复用成熟的 4DGS + HexPlane 结构，实现成本低。
- **深度时序一致性处理务实有效**：利用静态相机下背景深度不变这一先验，通过光流分离静态区域做尺度-偏移对齐，是简单但针对性的设计。
- **外部依赖最小化**：相对场景流等重先验，仅需单目深度，更贴近实际部署需求。
- **实验呈现规范**：给出逐场景细粒度结果，并在第二个数据集上提供定性验证，同时明确说明位姿对齐仅为评测所需，态度诚实。
- **效果显著**：在强基线 MoDGS 上取得约 4 dB 的平均 PSNR 提升，属于较大幅度的改进。

- **前置模块误差会级联**：整条流水线依赖单目深度（Depth Pro）+ 精炼网络 + SEA-RAFT 光流 + 静态背景掩码。若场景中存在大面积动态前景遮挡背景、或相机本身几乎无运动导致光流不可靠，静态区域分离与尺度-偏移估计可能失效，进而污染代理图像，而论文未对这类失败情形做敏感性分析或失效案例展示。
- **"静态背景"假设较强**：时序一致性校正建立在"静态相机下背景深度不随时间变化"这一前提上，对存在摄像机微动、背景中含缓慢运动元素（如流水、蒸汽、飘动布料——DyNeRF 场景中恰好有火焰与蒸汽）的情形，该假设可能被违反，但论文未讨论掩码阈值与鲁棒性。
- **代理图像质量上限受限于深度质量**：代理图像的几何正确性完全由单张深度图决定，前向投影在大视角偏移、遮挡边界处会出现空洞、拉伸与伪影；论文未量化代理视角与真实相机的偏差，也未报告代理图像本身的渲染质量。
- **超参数与实现细节披露不足**：虚拟相机的前半球采样半径、俯仰范围、M 的取值依据、100 步优化的学习率与初始化策略、损失权重等关键超参均未给出消融或敏感性分析，复现难度较高。
- **效率指标缺失**：如前所述，端到端（含深度估计、精炼、光流、逐帧代理生成）的时间与显存开销未报告，无法与基线做公平的效率对比；"单卡 3 小时"仅覆盖主训练阶段。
- **与最新方法的比较缺位**：未与 2025 年以来的动态 3DGS 新工作对比，难以确认相对当前 SOTA 的定位。
- **创新性边界**：核心组件（Depth Pro、Neural Disparity Refinement、SEA-RAFT、4DGS、HexPlane）均为已有工作，本文贡献主要在于"深度引导代理图像 + 4DGS"的组合式流程设计，方法层面的原创性偏向工程整合而非新表示或新理论。

## 九、总体评价与可借鉴点

- **定位**：这是一篇问题定义清晰、工程实现务实的动态新视角合成工作，其最大价值在于**重新框定了问题**——把"单目静态相机下的 4D 重建"从"堆叠更强先验"转向"主动合成缺失的多视角监督"，这一视角对后续研究具有启发意义。
- **核心可借鉴设计**：
  1. **"用完即弃"的轻量代理表示**：用仅优化约 100 步的临时 3DGS 生成监督信号，而不追求代理本身的长期保真，显著降低了合成监督的成本，是可推广的范式。
  2. **深度作为中枢模态**：以深度同时承担（a）几何初始化、（b）代理图像生成、（c）深度监督三重角色，形成自洽的训练闭环。
  3. **静态背景驱动的尺度对齐**：借"相机静止 → 背景深度不变"的物理先验，用光流掩码做尺度-偏移校正，方法简单、计算廉价，适用于任何依赖单目深度的时序任务。
  4. **SSI 深度损失 + 可见区域 RGB 损失**：规避了单目深度与重建深度的尺度歧义，也避免了对代理图像不可见区域的错误监督。
- **适用场景判断**：方法最契合**相机运动平缓、场景以静态背景为主、前景动态物体占比适中**的视频；对于手持大幅抖动、纯旋转无平移、或背景本身高度动态的场景，可靠性存疑。
- **后续可探索方向**：
  - 在真实野外单目视频（如 DAVIS、iPhone 手持视频）上做无 GT 视角的定量/人评评测，检验实用性；
  - 引入代理图像质量的自适应加权或不确定性建模，抑制低质量代理视角的负面影响；
  - 让虚拟视角采样与真实相机位姿的估计联合优化，减少训练/测试视角分布耦合；
  - 探索动态前景区域的多视角监督构造（当前静态掩码把动态部分排除在对齐之外）。

---

## 十、一句话总结

ProDyGS 通过"单目深度 → 时序对齐 → 前向投影生成代理图像 → 4DGS 训练"的流水线，用最小化的外部先验人工补回单目静态相机缺失的多视角几何监督，在 DyNeRF 上以约 4 dB 的 PSNR 优势超越依赖更强先验的 MoDGS，方法简洁有效，但评测数据集与视角协议偏理想化，泛化性与端到端效率仍有待验证。

（完）
