## 摘要
从自然中重建并动画化水景可产生引人入胜且沉浸式的视觉体验。先前工作从2D视频纹理的角度研究该任务，目标是生成循环视频。在我们的工作中，我们从3D视角处理该问题，创建循环的4D动态重建，使其能够从单个非循环2D源视频中从新视角进行交互式渲染。我们将运动表示为3D静态欧拉运动场，该运动场平流规范高斯泼溅，这些高斯泼溅在固定时间段循环重生，并使用渲染损失进行监督。为了建模真实场景中存在的非周期和随机动态，我们添加一个非周期、时变的残差项，以捕捉相对于静态欧拉运动场的偏差。我们定量和定性地表明，我们的框架能够实现比先前技术更好的水景照片级真实感动画。

## Abstract
Reconstructing and animating water scenery from nature produces compelling and immersive visual experiences. Previous work examined this task from the perspective of 2D video textures, with the goal of creating a looping video. In our work, we tackle the problem from a 3D perspective, creating a looping 4D dynamic reconstruction which can be interactively rendered from novel viewpoints from a single non-looping 2D source video. We represent motion as a 3D static \textit{Eulerian} motion field that advects canonical Gaussian splats that are cyclically reborn at fixed time periods, supervised using rendering losses. To model non-periodic and stochastic dynamics present in real-world scenes, we add a non-periodic, time-varying residual term to capture deviations from the static Eulerian motion field. We show quantitatively and qualitatively that our framework enables photorealistic animation of water scenes better than prior art.

# 论文总结：Eulerian Motion Reconstruction for Water Scenery（面向水景的欧拉运动重建）

## 1. 核心问题与整体含义

- **研究动机**：水景（湖泊、河流、瀑布等）在自然中无处不在，逼真地重建并动画化这类动态，能让虚拟 3D 世界更具沉浸感。为使这类体验可规模化创建，论文聚焦于**从随手拍摄的单目 2D 视频**出发，构建 4D 重建。
- **背景与难点**：
  - 既有 4D 重建工作（D-NeRF、4DGS、MoSca 等）多针对**持续存在的刚体/非刚体对象**，假设动态物体始终留在视野内、进出视野的物体很少，运动可建模为从规范空间出发的空间形变。
  - 水景的本质是**流体粒子快速流入流出视野**，且同时存在"重复性"与"随机性"的复杂交织，传统形变场建模方式失效。
  - 先前的循环 3D 表示（如 3D Video Loops、Multi-Tile Video）通常需要**多视角同步/异步视频采集**；而本文处理更具挑战性但更可扩展的**单目视频**场景，同一时刻只有一个视角被观测到。
- **整体含义**：论文将 2D 循环视频纹理的思想推广到 3D，提出一种**可无限循环的 4D 动态重建**，支持新视角合成、无限循环动画与一致的水粒子 3D 跟踪。

## 2. 方法论

### 2.1 核心思想
将水景运动分解为**周期性主导成分**（静态欧拉运动场 + 循环平流的高斯基元）与**非周期残差成分**（时变残差变形场），并通过渲染损失端到端联合优化。

### 2.2 关键技术细节

- **场景表示**：
  - 规范空间中的 N 个 3D 高斯泼溅 $G_n = (X_n, S_n, R_n, O_n, C_n)$，分别表示位置、尺度、朝向、不透明度、颜色。
  - 运动由**隐式 3D 欧拉运动场** $V(x,y,z)$ 表达，该场**不随时间变化**。直观上，$V(X)$ 是水粒子到达空间点 $X$ 时的速度。
  - $V(X)$ 初始化为相邻帧 2D 光流的三维反投影结果。

- **循环平流（Forward Euler Integration）**：
  - 通过前向欧拉积分推进高斯位置：$X_{n,t} = X_{n,t-1} + V(X_{n,t-1})$，$t \in \{0,\dots,L\}$。
  - 若无限推进，高斯终将流出场景导致空场，因此每 L 帧（cycle length）将高斯**重生回规范位置**，形成无限长的 4D 动态场景。
  - **关键设计——随机起始时间**：若所有高斯同时重生，整场会像刚体一样瞬移回顶部，产生可见"跳跃"伪影（Fig. 3a）。论文改为对每个高斯从其出生时间 $t_0^n \sim \text{Uniform}[0, L]$ 随机采样，使重生在循环内**错开**（Fig. 3b），形成"传送带"式的自然流动。
  - 训练时用 Alg. 1（复杂度 $O(NL)$ 从规范位置推进到目标 cycle index）；推理时用 Alg. 2（首帧 $O(NL)$ 初始化，之后每帧仅 $O(N)$ 单步推进），复用每个周期的传播结果。

- **非周期残差变形**：
  - 学习时变残差场 $D(X_n, t_n, p_n)$，对高斯的位置、颜色、不透明度预测**加性偏移**。
  - 时间被分解为循环内索引与循环编号：
    - $t_n = (i - T^{\text{start}}_n) \bmod L$（自上次重生以来的积分步数）
    - $p_n = \lfloor (i - T^{\text{start}}_n) / L \rfloor$（在输入视频中已完成的完整周期数）
  - 残差是**直接相加**而非随时间积分；推理时设 $p_n = 0$，即使用第一周期的残差，保证 4D 动画仍为周期性。

- **初始化（分阶段）**：
  - Stage 1：忽略运动，用静态重建拟合规范高斯，相机位姿由标准 SFM 工具箱推断。
  - Stage 2：用现成光流预测器（PTLFlow）计算相邻帧 2D 光流，借助静态重建的渲染深度将其提升为 3D 场景流，得到伪真值 $\{(X, V'(X))\}$ 对，预训练欧拉运动场 $V$。
  - Stage 3：联合训练 $\{G_n\}$、$V$、$D$，用 L1 + SSIM 渲染损失，并对 $D$ 加 L2 正则。

- **实现细节**：
  - $V$ 与 $D$ 均用 triplane 实现；$V$ 的 MLP 只接收位置特征，$D$ 的 MLP 额外接收正弦编码的 cycle index 与 cycle number。
  - $V$：triplane 分辨率 128/轴、12 通道，MLP 宽度 64、深度 2，输出 3D 速度。
  - $D$：triplane 分辨率 128/轴、16 通道，MLP 宽度 128、深度 2，输出 52 维（位置/不透明度/颜色残差）。
  - 高斯泼溅使用 RayGS 实现；先用 SAM 3 得到逐帧水掩码，学习逐高斯动态概率（阈值 0.2）区分动/静高斯，每 10 步更新。
  - 损失权重：L1 = 0.8，SSIM = 0.2，L2 正则 = 0.001，分割 BCE = 0.5。
  - 静态重建训练 10k 迭代，动态微调 20k 迭代；cycle length 取 $L=15$。

## 3. 实验设计

- **数据集**：因缺乏单目水景专用数据集，作者**自采集 7 个场景**（Greenacre Park、Garden、Parley Falls、Creek、Sculpture、Waterstep、Village Park），分辨率 1168×880、30 fps、约 25 秒，含平移与旋转以提供视差；用 COLMAP 重建稀疏点云并估计相机参数。
- **评测协议**：每场景 750–800 帧（660/710 训练、90 测试），测试集为**3 段各 30 帧的留出片段**（沿用 AmbGS 的做法），仅在这些片段上评测，以避免只衡量训练帧间的插值。
- **对比基线（4 类代表）**：
  - AmbGS（依赖密集视角覆盖 + 形变场）
  - MoSca（依赖 2D 跟踪与单目深度等图像先验）
  - 4DGS（通用 4D 基元表示动态）
  - MoVieS（前馈式 4D 重建，直接预测几何/外观/运动）
- **评价指标**：全图与**水区域**分别报告 PSNR、SSIM、LPIPS、FID、KID、FVD（后三者按 Lift4D 的分布式评测协议）。
- **用户研究**：25 名参与者、7 个场景、共 2100 次判断；三种设置——Appearance（相机移动、场景冻结）、Motion（相机固定、时间推进）、Reference（相机与时间同时推进，与真实留出素材并排比较）。
- **消融实验**：去除欧拉运动场、去除光流初始化、去除非周期残差、替换为静态重建、去除 Alg. 1（取消随机起始时间）；另有 cycle length $L \in \{15, 25, 35\}$ 的消融；并做场景流轨迹可视化与 x–t 切片分析。

## 4. 资源与算力

- 论文明确说明：**每个场景约需 8 小时，在 8 张 A6000 GPU 上训练**。
- 推理速度：单张 A6000 上，Alg. 2 相比训练时的 Alg. 1 有约 **3–4 倍加速**（15 帧 1 周期时端到端 0.270 s vs 0.719 s；450 帧 30 周期时 7.072 s vs 28.232 s）。
- 基线运行受限：MoSca 在分辨率大于 600×600 时失败，故其结果被上采样后比较；MoVieS 因显存限制需将输入下采样至 170 帧、半分辨率，再上采样比较。

## 5. 实验数量与充分性

- **实验组数**：
  - 7 个场景 × 4 个基线的定量对比（全图 + 水区域共 12 项指标）。
  - 1 组用户研究（2100 次判断）。
  - 5 个组件级消融 + 3 档 cycle length 消融。
  - 定性对比：重建图像对比、场景流轨迹对比、固定新视角下的时间演化对比、x–t 切片分析。
- **充分性评价**：
  - 整体较为充分：既有全参考指标（PSNR/SSIM/LPIPS），又有分布式指标（FID/KID/FVD），并单独在水区域评测，针对性强；用户研究规模合理且包含三种感知维度。
  - 消融覆盖了每个提出组件，且配有轨迹与 x–t 切片等可视化证据，论证较扎实。
- **公平性隐患**：
  - MoSca 与 MoVieS 的结果经过**上采样**后与其他方法比较，分辨率不匹配可能影响指标公平性（论文对此有说明，但偏差风险仍存在）。
  - 数据集为作者自采集且仅 7 个场景，缺少第三方公开基准，跨方法泛化性对比的说服力有限。
  - 论文未报告多次随机种子下的方差。

## 6. 主要结论与发现

- 所提框架在**大多数指标上优于基线**，在 LPIPS 与分布式指标（FID/KID/FVD）上**大幅领先**，说明其能重建自然、细节丰富的水外观与运动。
- 用户研究中，本方法在 **97.6% 的判断中被偏好**，在三种设置下均胜过所有基线；与最强的先验方法 AmbGS 在 Appearance 上差距最小（86.3%），但在 Motion 上扩大到 98.9%，表明**核心优势在于运动重建而非静态外观**。
- 场景流可视化显示：本方法的欧拉运动场产生**长且连贯、符合自然水流**的轨迹，而基线给出短、不连贯或近乎静止的轨迹。
- 消融结论：
  - 缺少欧拉运动场或光流初始化时，几乎无法重建水流运动（水粒子变成模糊条纹）。
  - 去除非周期残差会削弱随机性，导致无法拟合非循环输入，产生模糊结果。
  - 去除 Alg. 1（取消随机起始时间）时逐帧指标仅微降（约 −0.19 dB PSNR），但 FVD 显著上升，x–t 切片上出现跨整个宽度的水平条带——证明**错开重生对消除循环伪影至关重要，且此类伪影需用视频级指标才能反映**。
  - $L$ 越大可表达更丰富运动，但收敛更差、重建更模糊；$L=15$ 在运动范围与重建清晰度间取得最佳平衡。

## 7. 优点

- **建模思路新颖**：把 2D 视频纹理/欧拉运动场的思想系统性推广到 3D 4D 重建，用"静态欧拉运动场 + 循环重生"统一表达周期性与连续性，概念简洁优雅。
- **随机重生调度设计巧妙**：逐高斯随机起始时间以极低代价消除了循环边界处整场同步重置造成的跳跃伪影，是让循环表示真正可用的关键工程洞察。
- **周期性/非周期性解耦**：用不随时间变化的欧拉场捕捉主导重复模式，用轻量残差场拟合真实世界的随机偏差，既保持可循环性又提升保真度。
- **初始化策略务实有效**：以成对 2D 光流（而非易错的长程 2D 跟踪）加深度反投影得到伪场景流来预训练运动场

（接上）……，避免了对单目视频而言极不稳定、易漂移的长程跟踪依赖，使运动场预训练在单目条件下仍可落地。

- **评测维度设计有针对性**：同时报告全图指标与水区域指标，并引入 FVD/x–t 切片等**视频级/时空一致性**证据，恰好捕捉到逐帧指标无法反映的循环伪影问题，体现出对任务特性的深刻理解。
- **推理效率设计合理**：通过区分训练用的 Alg. 1 与推理用的 Alg. 2、复用周期传播结果，将每帧推理复杂度从 $O(NL)$ 降到 $O(N)$，使无限长循环动画在单卡上仍具实用速度。
- **诚实报告资源与限制**：明确给出训练时长、GPU 数量、基线的显存/分辨率限制及相应处理方式，可复现性描述较完整。

## 8. 局限性与不足

- **运动场为稳态假设的固有边界**：$V(x,y,z)$ 不随时间变化，意味着模型假定水流在空间上"重复且均匀"，对**方向反转、流速随时间剧烈变化、突发性事件（浪花、骤雨、涨落）**等场景表达力有限，非周期成分只能通过加性残差被动补偿。
- **依赖视频本身的循环性**：方法假设输入视频在 $L$ 帧内近似循环。若输入本身不循环或循环周期与 $L$ 不匹配，则残差场需要承担过多信息，可能退化。论文虽做 $L$ 的消融，但**未给出自动估计 $L$ 的方法**，需人工设定。
- **对初始化与预处理敏感**：性能依赖 SFM 相机位姿、PTLFlow 光流质量与 SAM 3 水掩码；光流在反射、透明、泡沫区域本就不稳定，错误会被提升进 3D 伪场景流并固化。论文未系统分析这些上游误差的传播影响。
- **动态/静态分离较启发式**：以逐高斯动态概率（阈值 0.2、每 10 步更新）区分动/静高斯，阈值与更新频率缺少敏感性分析，可能对不同场景需调参。
- **数据集规模与公平性**：7 个自采集场景、均为作者拍摄，缺少公开基准与跨数据集验证；基线因分辨率/显存被降采样或上采样，指标对比存在系统性偏差风险；未报告随机种子方差。
- **场景范围局限**：实验集中在**水面流动（溪流、瀑布、喷泉）**，未验证对海面大尺度波浪、含大量反射/折射的镜面水面、或水体与固体交互（浪花拍岸、溅射）的适用性。
- **评价的物理一致性**：主要靠视觉指标与用户研究，**缺少与真实 3D 流体物理量（速度场、流量）的定量比较**，所谓"物理合理"仅由外观与轨迹合理性间接支持。
- **计算成本**：单场景 8 小时 × 8 卡 A6000 仍属昂贵，与"可规模化"的目标存在张力。

## 9. 个人评价与启示

- **核心贡献定位**：本文的主要价值不在于提出新的表示基元（仍基于 3DGS），而在于**重新定义了"动态重建"的建模框架**——用"不随时间变化的欧拉运动场 + 循环平流 + 错开重生"替代传统的"规范空间 + 形变场"，为"持续流动、粒子不断进出视野"的介质类动态（水、烟、火、云）提供了一条统一且可无限延展的重建路径。这一视角转换具有较强的迁移潜力。
- **方法论启示**：
  - **"周期性 + 残差"的解耦范式**值得借鉴：将主导规律性成分用简洁、可外推的参数化形式表达，把难以建模的随机偏差交给轻量残差网络，兼顾可循环性与保真度。
  - **随机重生调度**是一个"小改动、大收益"的典型设计：以极低成本解决循环表示的边界伪影，提示在处理周期性表示时，**相位错开（phase staggering）**往往是必要且高效的。
  - **伪真值预训练策略**（2D 光流 + 深度反投影 → 3D 场景流）为单目动态重建提供了一条务实的冷启动路径，规避了长程跟踪的脆弱性。
  - **指标选择的经验**：作者发现逐帧 PSNR 对循环伪影几乎不敏感（仅 −0.19 dB），而 FVD/x–t 切片能显著暴露问题。这提醒后续工作在评估时空一致性问题时，**必须引入视频级指标与时空可视化**，不能只看单帧质量。
- **可改进方向**：
  - 引入**随时间缓变的运动场**（如低频时间调制、或分段稳态场切换）以突破稳态假设。
  - 用**数据驱动方式估计 cycle length**，或让 $L$ 可学习。
  - 增加**物理先验约束**（不可压性、边界条件）以提升运动的物理合理性。
  - 扩展到更广的介质与公开基准，并报告方差与误差传播分析。
- **总体判断**：论文问题定义清晰、方法自洽、工程实现完整、实验维度覆盖较全（定量 + 定性 + 用户研究 + 消融 + 时空分析），在"单目水景 4D 重建"这一具体且困难的设定下取得了令人信服的进展。其局限主要来自稳态运动场假设与自建数据集规模，属于"方法边界"而非"实现缺陷"，为后续研究留下了明确且有意义的空间。
