tldr: 构建交互式数字孪生需要同时恢复三维几何与支配物体运动的运动学结构，但现有铰接物体重建方法要求在多铰接状态下显式观测运动。本文提出静止状态重建范式，仅从单一闭合构型出发，在几何、语义与运动先验的补偿下应对这一病态问题。框架以显式网格作为中间表示进行跨模型验证与融合，将视觉语言与分割模型的噪声输出整合为空间一致的分部件结构，从而在无运动线索时估计关节参数。

## Abstract
Building interactive digital twins requires recovering both 3Dgeometry and the kinematic structures that govern how objects articu-late. Yet existing methods for articulated object reconstruction requireexplicitly observable motion from multiple articulation states. We intro-duce a rest-state formulation that reconstructs articulated objects froma single closed configuration, an inherently ill-posed setting where geom-etry, semantics, and motion priors compensate for the absence of motioncues. Our framework adopts an explicit mesh as an intermediate repre-sentation for cross-model verification and fusion, reconciling noisy out-puts from vision-language and segmentation models into spatially con-sistent part structures. To estimate joint parameters without observedmotion, we use a video diffusion model to synthesize articulation hy-potheses and validate them through geometric consistency. Our approachachieves accurate part decomposition and physically plausible articu-lation, performing competitively with motion-observing reconstruction-based, generation-based, and modular pretrained-model baselines.

- **背景需求**：构建交互式数字孪生（digital twin）需要同时恢复物体的三维几何与支配其运动的运动学结构（关节类型、轴向、位置、位移/转角）。
- **现有方法的强约束**：当前铰接物体重建方法普遍要求**多铰接状态**的显式运动观测（如开门前后两帧、交互视频），并常常预设可动部件数量，例如 Ditto、PARIS、DTA、ArtGS、REArtGS 系列等。即便如 Real2Code 这类单状态方法，其输入也必须是"已铰接"（部件已发生位移、视觉上可分辨）的状态。
- **核心痛点**：现实中物体绝大多数时候处于**闭合静止状态（rest state）**——它也是产品图、互联网图像、ScanNet/Replica 等场景级数据集中最可靠、可规模化获取的构型。但在此构型下，几何、语义与运动线索同时缺失，重建在数学上是**病态问题（ill-posed）**。
- **关键观察**：
  - 预训练模型（VLM、分割模型、视频扩散模型）可提供丰富的语义与运动先验；
  - 但它们的输出彼此冲突且含噪：VLM 预测的部件层级不完整、分割模型在部分视角漏检、视频扩散模型会**幻觉出不存在的抽屉**（论文 Fig. 2 给出具体案例）。
- **论文定位**：提出 **Rest2Art** 框架，仅凭单一闭合构型（rest-state）恢复多部件铰接结构，不依赖运动观测、不依赖部件数量先验，并通过"以显式网格为锚点做跨模型交叉验证"来调和上述噪声。

## 2. 方法论

### 2.1 核心思想

- 将**显式表面网格（mesh）作为中间表示**，而非点云或神经场。理由：网格显式编码表面连通性，支持精确的遮挡推理、空间一致的部件边界，以及作为多模型输出的置信度加权融合锚点。
- 设计原则是**"以几何验证替代顺序串联"**：不把预训练模型串行拼接（如 Articulate AnyMesh），而是让各模型输出在网格上互相校验。
- 框架与输入源无关（input-agnostic）：多视角重建、单图 3D 生成、已有 3D 资产/场景扫描均可作为输入。

### 2.2 问题形式化（Sec. 3.1）

- 输入：rest-state 物体网格；输出：部件网格 $\{M_k\}_{k=1}^{K}$ 与关节参数 $\{\Psi_k\}_{k=1}^{K-1}$，其中 $K$ **自动确定**，无需标注。
- 物体建模为刚体部件集合，通过 SE(3) 变换描述运动，仅考虑两类关节：
  - **移动关节（prismatic）**：$\Psi^p=\{v\in\mathbb{R}^3, d\in\mathbb{R}\}$，$v$ 为平移方向，$d$ 为标量位移；
  - **旋转关节（revolute）**：$\Psi^r=\{\omega\in\mathbb{R}^3, q\in\mathbb{R}^3, \theta\in\mathbb{R}\}$，$\omega$ 为旋转轴方向，$q$ 为轴上一点，$\theta$ 为旋转角。

### 2.3 第一阶段：部件分割（Sec. 3.2）

- **初始网格获取与视角选择**：对网格做规范化对齐，并从 $N'$ 个最大化可动部件可见性的视角重渲染。
- **层级树与掩码协同精炼（co-refinement）**：
  - VLM（GPT-5.2 / Qwen3-VL）提出候选层级树 $T$，抽取语义提示集 $S(T)=\{s_1,\dots,s_C\}$ 及每个类别的期望实例数 $n(s,T)$；SAM3 对每个提示在每个视角产出掩码 $M_{v,s}$。
  - 比较检测数 $|M_{v,s}|$ 与 $n(s,T)$，分三种情形处理：
    - **一致**：掩码作为该视角的已验证证据缓存；
    - **过量检测**（$|M_{v,s}|>n(s,T)$）：判定 $T$ 不完整，将检测掩码以鲜艳颜色叠加到输入视图（使无纹理物体的部件边界可视化），回灌 VLM 修正 $T$，然后**重启验证**；
    - **漏检**（$|M_{v,s}|<n(s,T)$）：不裁剪 $T$，而是跨视角聚合证据后再判定。
  - 精炼轮数上限固定为 2 轮。
  - **跨视角一致性**：将高置信掩码反投影为 3D 表面点，再重投影到其他视角作为**点提示**查询分割模型；仅当提示掩码与已缓存掩码一致时才接受。
- **置信度加权证据抬升（evidence lifting）**：
  - 对每个部件 $p$，按"检测置信度 + 掩码覆盖率"排序，选 top-$K$ 视角 $V_p$；
  - 用 z-buffer 渲染 + 背面剔除得到逐像素面索引图 $\phi_v$，掩码的面支撑集为 $\mathrm{supp}(M_p^v)=\{f\in\mathcal{F}\mid \exists\,\mathbf{x}\in M_p^v,\ \phi_v(\mathbf{x})=f\}$；
  - 逐面逐部件累积证据：$E(f,p)=\sum_{v\in V_p} w_p^v\cdot c_p^v\cdot \mathbb{1}[f\in\mathrm{supp}(M_p^v)]$，其中 $w_p^v$ 为归一化视角权重、$c_p^v$ 为检测置信度；
  - 面标签取 $\ell(f)=\arg\max_p E(f,p)$，无任何支撑的面默认归为**基座部件（base part）**。
- **基于图的精炼**：针对三类残留错误（多视角冲突导致的边界不一致、噪声碎片、欠分割区域）依次处理：
  - 对每个标签取面级连通分量的**主导分量**作为种子，其余碎片进入未分配池 $\mathcal{U}$；
  - 在顶点邻接图上做**多源最短路径**传播：$\ell(u)=\arg\min_p d_p(u)$，同距时以视角质量分破平（沿表面拓扑扩张，避免跨越几何不连续处）；
  - 最终**跨模态校验**：将重标定顶点投影回该部件的最佳视角，仅当落入对应 2D 掩码内才接受，否则改判给次近部件。

### 2.4 第二阶段：关节估计（Sec. 3.3）

- **核心策略**：合成运动只作为**假设来源**，最终关节参数由**几何一致性（网格）**决定，而非生成视频的保真度。
- **铰接视频合成**：
  - 将部件掩码以半透明方式叠加到全图平均质量最高的视角，作为单张条件图显式高亮所有可动部件；VLM 生成描述预期运动的文本提示；
  - 使用 **Wan2.2 + VBVR LoRA**（后者鼓励对连续性、因果性等物理属性的时空推理）；
  - 用 **CoTracker3** 提取稠密 2D 点轨迹，跟踪点在首帧初始化于各部件掩码区域；借助网格渲染提供的度量深度，将首帧位置反投影为 3D 相机系**静止姿态锚点** $\{p_0^j\}$；
  - **轨迹截断**：在可见轨迹比例首次低于阈值的帧处截断，以同时应对生成视频的时序退化（误差累积导致运动不合理）与跟踪器漂移。
- **运动类型分类**（仅用 2D 轨迹）：
  - 线索一：逐点位移幅值的**变异系数（CV）**——旋转运动因不同半径点行程不同而 CV 高，移动运动 CV 低；
  - 线索二：位移向量方向随时间变化的**曲率分数**——旋转轨迹弯曲、移动轨迹笔直；
  - 位移可忽略者判为**静态**；两线索一致时直接采用，歧义时**两种模型都拟合**，取重投影误差更低者。
- **关节参数拟合**：以 2D 重投影误差最小化为目标，用已知相机内参投影回 2D，采用鲁棒损失降权外点，再做 trimmed refit。
  - 旋转：$\mathbf{p}_t=R(\hat{\omega},\theta_t)(\mathbf{p}_0-\mathbf{q})+\mathbf{q}$（Rodrigues 旋转）；
  - 移动：$\mathbf{p}_t=\mathbf{p}_0+d_t\hat{\mathbf{v}}$。
- **解决单目深度歧义**：多个 3D 旋转轴可产生相同的 2D 投影，故
  - 利用分割网格**惩罚导致子部件穿入父部件的轴配置**；
  - 将 $\hat{\omega}$ 与相邻部件边界的主方向**软融合**（该方向编码了物理铰接结构）。
- **鲁棒性增强**：用两个不同随机种子生成两段铰接视频，各自独立拟合；若运动类型一致，则合并轨迹证据联合重拟合。

### 2.5 第三阶段：网格补全（Sec. 3.4）

- 分割得到的部件是壳状面片，而物理仿真器与 URDF 导出需要**闭合体**。
- 方法：沿顶点法线**向内偏移**生成闭合网格；由于切割边缘

后可能存在开放边界，故需对切口做**封口处理**：沿部件被切割的边界环生成补面，使每个部件成为水密（watertight）的闭合实体；同时保留原始外表面几何不被改动，仅填补内部与切口区域。

- **关节侧的几何一致性约束**：补全后需检查子部件与父部件在铰接运动学下的干涉情况——即当关节按估计参数运动到极限角/位移时，子部件不应穿入父部件实体。若出现穿模，则回退到关节估计阶段调整轴配置（对应 Sec. 3.3 中"惩罚穿入的轴配置"），或对部件做最小化的局部收缩。
- **输出形式**：最终产出可导出的 URDF/关节层级描述与各部件闭合网格，可直接送入物理仿真器（如 MuJoCo、Isaac Sim）进行交互式数字孪生构建。

## 3. 实验设计与评估

### 3.1 数据集与基准

- **对象级评估**：在带有真实关节标注的铰接物体数据集（如 PartNet-Mobility / SAPIEN 中的柜类、抽屉柜、微波炉、笔记本电脑等）上评测，输入**仅取闭合静止构型**，与需要多状态观测的方法形成对照。
- **场景级评估**：在 ScanNet / Replica 等真实扫描数据中提取的静止物体上评测，检验方法对真实噪声几何（缺失面、扫描伪影）的鲁棒性。
- **真实世界采集**：额外使用多视角拍摄或单图 3D 生成的真实物体（含纹理与光照变化）验证泛化能力。

### 3.2 评估指标

- **几何指标**：部件分割的 mIoU / 边界 F-score（Chamfer 距离下的部件匹配），整体网格重建的 Chamfer 距离与法线一致性。
- **关节指标**：关节类型分类准确率；旋转轴方向误差（角度差，度）、轴上点距离误差、移动方向误差；以及在给定运动量下，预测运动与真值运动之间的**运动重投影误差**与部件位姿误差。
- **部件数量**：预测 $K$ 与真值部件数的匹配率，检验"无需部件数先验"的有效性。
- **下游任务指标**：URDF 导出后在仿真器中的可交互成功率、穿模发生率。

### 3.3 对比方法

- 多状态/交互式铰接重建方法（Ditto、PARIS、DTA 等）——在其输入被退化为单静止状态时的性能下降对比。
- 单状态方法（Real2Code 等）——需预置已铰接输入的对照。
- 神经场/点云表示的铰接方法（ArtGS、REArtGS 系列）。
- 消融：去掉网格锚点、去掉 VLM–分割协同精炼、去掉跨视角一致性、去掉视频扩散先验、去掉穿模惩罚等。

### 3.4 主要预期结论

- 在仅静止输入的设定下，Rest2Art 显著优于将多状态方法直接退化的基线，并在部件数量与关节参数精度上接近使用运动观测的方法。
- **网格作为中间表示的增益**：相比点云/神经场，显式连通性带来更一致的部件边界与更少的跨部件泄漏，尤其在薄壁、相邻可动部件紧贴的物体上。
- **交叉验证优于串行串联**：消除视频扩散模型的"幻觉抽屉"类错误，防止错误语义沿流水线传播。
- **视频仅作假设、几何做裁决**的设计，使关节参数对生成视频的时序退化不敏感。

## 4. 方法特点与创新点

1. **问题重定义**：把铰接重建从"需要运动观测"推进到"仅需单一闭合静止构型"，直击互联网与场景数据集的实际可获得形态，同时承认其病态性并以先验调和解决。
2. **网格锚定的多模型交叉验证**：不以流水线方式堆叠预训练模型，而是让 VLM、分割模型、视频扩散模型在显式网格上相互校验、置信度加权融合，从机制上抑制幻觉与冲突。
3. **自适应部件数量**：通过 VLM 层级树与掩码检测数的"一致 / 过量 / 漏检"三分支协同精炼，自动确定 $K$，不依赖部件数先验。
4. **假设—验证分离的关节估计**：视频扩散只提供运动假设，关节参数由 2D 重投影 + 网格几何（穿模惩罚、边界主方向软融合）共同裁决，并显式处理单目深度歧义。
5. **面向仿真的闭合输出**：网格补全与干涉检查保证可导出为 URDF 并直接用于物理仿真，打通从感知到交互式数字孪生的链路。

## 5. 局限性

- **依赖预训练模型质量**：VLM 的部件层级合理性、分割模型在无纹理/反光/透明物体上的表现、视频扩散模型对罕见关节类型的先验，均会传导到最终结果；交叉验证可缓解但难以完全消除。
- **关节类型受限**：目前仅支持移动与旋转两类单自由度关节，未覆盖螺旋、球窝、多自由度或联动机构。
- **单目深度歧义**：虽以穿模惩罚与边界方向软融合缓解，但在部件几何近似对称、边界主方向不明显时仍可能歧义。
- **封闭性假设**：物体须在静止态即可从外部观测到足够多的可动部件表面；完全内藏或遮挡严重的部件难以恢复。
- **计算开销**：多视角重渲染、逐面证据累积、两段视频生成与轨迹拟合带来较高成本，实时性受限。

## 6. 总结与意义

Rest2Art 提出了一条从"最易获得但信息最贫乏"的静止观测出发、恢复完整铰接结构的路径：以**显式网格**为几何与推理的共同锚点，以**跨模型交叉验证**替代不可靠的串行串联，以**假设—验证分离**把生成式先验限制在提出假设的角色，而把最终裁决权交还几何一致性。其价值不仅在于提升静止态铰接重建的精度，更在于为"从互联网级静态数据规模化构建可交互数字孪生"提供了可行范式，并明确了后续方向——扩展到更多关节类型、更强的遮挡与歧义处理、以及更低成本的实际部署。
