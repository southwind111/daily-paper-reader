## 摘要
空间推理，即基于3D理解来定位语言的能力，仍然是视觉语言模型（VLM）面临的一个持续挑战。我们识别出两个根本瓶颈：源于以2D为中心的预训练所导致的3D理解能力不足，以及由冗余3D信息引发的推理失败。为了解决这些问题，我们首先在回答给定问题之前构建一个最小充分集（MSS）：从专家模型中紧凑地选择3D感知结果。我们引入MSSR（最小充分空间推理器），一个实现这一原则的双智能体框架。感知智能体使用多功能感知工具箱以程序化方式查询3D场景，以提取充分信息，其中包括一个新颖的SOG（情境方向定位）模块，能够稳健地提取基于语言的方向。随后，推理智能体迭代地精炼这些信息以追求最小性，在闭环中修剪冗余细节并请求缺失信息，直到MSS被整理完成。大量实验表明，我们的方法通过明确追求充分性和最小性，显著提高了准确性，并在两个具有挑战性的基准上达到了最先进的性能。此外，我们的框架产生了可解释的推理路径，为未来模型提供了高质量训练数据的有前景来源。源代码可在https://github.com/gyj155/mssr获取。

## Abstract
Spatial reasoning, the ability to ground language in 3D understanding, remains a persistent challenge for Vision-Language Models (VLMs). We identify two fundamental bottlenecks: inadequate 3D understanding capabilities stemming from 2D-centric pre-training, and reasoning failures induced by redundant 3D information. To address these, we first construct a Minimal Sufficient Set (MSS) of information before answering a given question: a compact selection of 3D perception results from \textit{expert models}. We introduce MSSR (Minimal Sufficient Spatial Reasoner), a dual-agent framework that implements this principle. A Perception Agent programmatically queries 3D scenes using a versatile perception toolbox to extract sufficient information, including a novel SOG (Situated Orientation Grounding) module that robustly extracts language-grounded directions. A Reasoning Agent then iteratively refines this information to pursue minimality, pruning redundant details and requesting missing ones in a closed loop until the MSS is curated. Extensive experiments demonstrate that our method, by explicitly pursuing both sufficiency and minimality, significantly improves accuracy and achieves state-of-the-art performance across two challenging benchmarks. Furthermore, our framework produces interpretable reasoning paths, offering a promising source of high-quality training data for future models. Source code is available at https://github.com/gyj155/mssr.

# 论文总结：Pursuing Minimal Sufficiency in Spatial Reasoning（MSSR）

## 1. 核心问题与整体含义

- **研究背景**：空间推理（将语言锚定到3D理解）是通用智能的基石，对机器人、AR/VR等物理世界部署至关重要。尽管现代VLM在诸多任务上表现优异，但在空间推理任务上仍持续失败。
- **两大瓶颈诊断**：
  - **3D感知不足**：VLM主要以2D数据预训练，缺乏几何先验，难以感知布局、朝向、深度等3D信息。
  - **冗余信息损害推理**：3D环境信息密集，朴素聚合所有感知结果会淹没上下文、稀释注意力、诱发捷径启发式，最终降低性能。
- **核心洞察**：借鉴认知科学（人类通过构建任务特定的最小心智模型来导航复杂场景）和统计学中的**最小充分统计量**概念，论文提出空间推理的关键在于主动发现**最小充分集（MSS）**——回答特定查询所需的最紧凑空间信息表示。
- **整体含义**：将3D空间推理形式化为MSS构建问题，通过双智能体闭环框架在"充分性"与"最小性"之间取得平衡，从而提升推理准确率并产出可解释的推理路径。

## 2. 方法论

### 2.1 核心思想
- 在回答3D推理问题前，先构建**最小充分集（MSS）**：既包含足够信息供推理（充分性），又剔除冗余/无关信息（最小性）。
- 形式化定义：设W为从完整3D场景可导出的所有空间与语义信息集合，目标是找到S* ⊆ W，满足：
  - **充分性**：R*(S*, q) = a*（oracle推理智能体基于S*能正确回答查询q）
  - **最小性**：∀S' ⊂ S*，R*(S', q) ≠ a*（任何真子集都不足以正确回答）
- 通过双智能体闭环协作迭代逼近MSS。

### 2.2 双智能体架构

**感知智能体（Perception Agent, PA）**：
- 采用**视觉编程（Visual Programming）**范式，接收当前信息集S、原始查询q、场景图像I和推理智能体的自然语言请求r，生成Python脚本调用专家模块。
- 初始指令宽泛（"尽可能提取所有潜在相关信息"），后续根据请求精准补充。
- **关键机制**：每次执行后保存Python环境完整快照，后续调用时重载，避免重复计算，支持有状态探索。
- **核心模块**：
  - **基础3D场景重建**：使用VGGT等快速神经重建模型估计相机参数、深度图和统一3D点云，并分割地面平面。
  - **全局坐标系校准**：基于参考向量（查询中的显式指令或显著地标）对齐场景轴，解决"左/后"等视角依赖术语的歧义。
  - **情境方向定位（SOG）**：将方向估计重构为**多选视觉选择任务**，而非直接回归3D坐标。采用**由粗到细策略**：先生成4个共面正交候选向量，渲染到"情境视图"（原始图像）和"规范视图"（合成俯视视角）上，VLM选择最匹配的向量；再在选中向量周围生成更密集的5个候选向量重复选择，收敛到精确方向。支持物体内在朝向和情境依赖朝向（如"上楼时人的朝向"）。
  - **数值计算模块**：计算相对相机运动（平移+旋转分解）和相对物体位置（相机坐标系下的右/上/前距离）。

**推理智能体（Reasoning Agent, RA）**：
- 两阶段过程：
  - **计划引导的信息整理**：制定高层推理计划，系统审视S_n中每一项，仅保留与计划相关的项到S_{n+1}，积极剪枝无关信息。
  - **策略决策**：若S_{n+1}不足，发出`<Request>`（精准描述缺失信息）返回PA；若充分，触发`<Decide>`，丢弃所有先前上下文，仅基于最终MSS用CoT推理得出答案。
- 两个智能体均**零样本**运行，由高层原则引导而非ICL示例，具有强泛化能力。

### 2.3 算法流程（文字说明）
1. 初始化S为空，PA执行宽泛感知指令填充S。
2. RA制定推理计划，剪枝S中无关项得到S_{n+1}。
3. RA判断充分性：不足则发`<Request>`，PA基于快照和请求生成新信息，更新S；充分则`<Decide>`。
4. 循环直至RA判定充分或达到最大迭代次数，最终仅基于MSS推理输出答案。

## 3. 实验设计

### 3.1 数据集与Benchmark
- **MMSI-Bench**：手工构建的多图像数据集，探测模型对相机、物体、区域三元素的位置、属性和运动的理解，含**多步推理（MSR）**子任务。
- **ViewSpatial-Bench**：评估多视角空间定位与识别，含5类任务，测试自我中心与异我中心空间推理的泛化能力。
- **补充评估**：ScanQA和SQA3D（物体中心QA，从场景视频均匀采样16帧）。

### 3.2 对比方法
- **专有LLM**：o3、Gemini 2.5 Pro/Flash、GPT-4o（骨干）。
- **开源LLM**：Llama-3.2-11B-Vision、LLaVA-OneVision-7B、Qwen2.5-VL系列、Qwen3-VL系列、InternVL2.5/3等。
- **3D-VLM**：Video-3D-LLM、LLaVA-3D、VLM-3R。
- **专家模型**：LEO。
- **智能体框架**：ViLaSR、VADAR。

### 3.3 主要结果
- MMSI-Bench总体准确率**49.5%**，超越最强LLM o3（41.0%）8.5个百分点，相对最佳开源LLM（Qwen3-VL-8B 31.1%）提升超60%。
- ViewSpatial-Bench总体准确率**51.8%**，Camera Based 51.0%，Person Based 54.4%。
- 消融实验：仅PA（33.8% MSR）、仅RA（31.8%）、无SOG（47.0%）、无迭代（44.4%）。
- 最小性效果：信息集元素从17.3降至5.9，准确率从45.8%升至48.3%。
- 骨干泛化：Qwen2.5-VL-7B从25.9%提升至39.8%（+13.9%）。
- 数据标注应用：用MSSR标注数据微调Qwen2.5-VL-7B，准确率从25.9%升至30.1%（+4.2%）。

## 4. 资源与算力

- **硬件**：8块NVIDIA 3090 GPU服务器，8个独立推理进程并行，每进程独占1块GPU。
- **微调**：4块NVIDIA A6000 GPU，使用LLaMAFactory + LoRA，全局batch size 32，训练5个epoch（约45步），峰值学习率2×10⁻⁵，余弦衰减，3% warmup。
- **推理时间**：每次迭代平均45.4秒，其中LLM API调用37.1秒（占81.7%），本地视觉模块8.3秒（占18.3%）。
- **迭代次数**：MMSI-Bench平均2.15次（MSR 2.41次），ViewSpatial-Bench平均1.88次。
- **效率对比**：MSSR总时间86.6秒 vs VADAR 52.5秒，内存7GB vs 5GB，但准确率51.8% vs 28.9%。

- **充分性评估**：

  - 消融实验系统性地隔离了各组件贡献，最小性实验通过"充分性归一化"控制变量，设计严谨。
  - 跨模型配置分析了PA和RA的敏感性差异，具有实用价值。
  - 失败分析基于人工检查半数失败案例，虽非全部但具代表性。
- **公平性**：与多种类型基线（专有/开源/3D-VLM/专家/智能体）对比，零样本设置下与2-shot通用VLM对比，较为客观。但ScanQA/SQA3D上因评估指标（CIDEr/EM）偏向文本匹配，与全监督方法对比存在天然劣势，论文已指出。

## 6. 主要结论与发现

- 显式追求**充分性与最小性**可显著提升空间推理准确率，MSSR在两个挑战性基准上达到SOTA。
- **冗余信息确实损害推理**：信息集越大准确率越低，剪枝至最小集后准确率提升。
- **双智能体协同不可或缺**：仅PA或仅RA均显著低于完整框架。
- **SOG模块有效**：将方向回归重构为视觉选择任务，解决了VLM无法直接回归3D坐标的局限。
- **迭代反馈对多步任务尤为关键**：MSR子任务上无迭代的性能下降更明显。
- **框架具有骨干泛化性**：性能随骨干能力可预测地扩展；PA对骨干能力更敏感，RA相对鲁棒，支持成本效益部署（强PA+轻RA保留90%性能）。
- **MSSR可作为数据标注引擎**：产出的MSS和推理轨迹可合成CoT数据，微调后7B模型达到接近72B模型的水平。
- **感知错误是主要失败来源**（55.9%），其中物体定位占32.9%；推理错误占31.7%，逻辑错误为主。

## 7. 优点

- **理论动机清晰**：将统计学的最小充分统计量与认知科学的心智模型理论结合，为空间推理提供了优雅的形式化框架。
- **零样本、免训练**：无需昂贵的3D指令数据集，避免灾难性遗忘，保留VLM通用能力。
- **闭环迭代设计**：不同于以往纯累积式智能体，MSSR主动剪枝冗余并精准请求缺失信息，直击冗余损害推理的痛点。
- **SOG模块创新**：将难以处理的3D方向回归转化为可靠的视觉多选任务，支持情境依赖朝向，扩展了可处理查询范围。
- **状态快照机制**：保存Python环境状态，支持有状态探索，避免重复计算。
- **可解释性强**：产出紧凑的MSS和显式推理轨迹，既便于调试，又可作为高质量训练数据。
- **实验全面**：覆盖主基准、消融、泛化、鲁棒性、失败分析、数据标注应用，论证充分。
- **成本效益分析**：揭示PA/RA对骨干能力的敏感性差异，提供实用部署策略。

## 8. 不足与局限

- **感知质量依赖**：框架依赖3D重建模型的几何信息，在极端视角、镜面反射、遮挡等挑战场景下可能产生噪声或不稳定结果，错误会传播到下游模块。
- **缺乏感知验证机制**：PA的数值错误（如噪声边界框、深度估计）难以被RA检测，逻辑错误可通过代码审查缓解，但数值错误需要外部验证。论文建议未来引入专门的验证智能体。
- **推理延迟较高**：MSSR总推理时间86.6秒，显著高于VADAR的52.5秒，主要开销来自RA的迭代推理（49.5秒），在对延迟敏感的应用中可能受限。
- **失败模式**：物体定位（23.0%）、3D重建（15.1%）、分割（9.9%）、SOG（7.9%）等感知错误占主导；RA的逻辑错误（21.4%）和计划错误（6.7%）也存在。约6%失败案例出现"循环"行为（RA反复请求PA无法提供的信息）。
- **基准覆盖有限**：主要在室内场景的多视角基准上评估，对户外、动态场景、更大规模场景的泛化性未充分验证。
- **ScanQA/SQA3D对比劣势**：因评估指标偏向文本匹配且非训练方法，与全监督专家模型存在差距。
- **微调实验规模较小**：仅300题采样、258条轨迹、5个epoch，虽显示潜力但需更大规模验证。
- **SOG精度限制**：非为亚度级精度设计，虽对多数任务足够，但在需要极高方向精度的场景可能不足。
- **问题歧义与输出解析错误**：占失败案例的12.3%，属于框架外的系统性风险。
